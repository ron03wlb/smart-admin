# iGaming 業務指標框架

> **受眾（Audience）**: 高階主管、產品經理、分析師、運營管理
> **文件類型**: 業務需求 - 運營與業務指標
> **XREF**: KPI 定義與計算公式見 [KPI 定義](01_KPI_Definitions.md) | 報表架構見 [報表需求](../08_Analytics_Operations/01_Reporting_Requirements.md)
> **最後更新**: 2026-03-31

---

## 概覽

本文件定義 iGaming 平台的**業務指標框架**，包含指標的業務意義、監控閾值、告警規則及改善行動。

---

## 1. 北極星指標（North Star Metrics）

iGaming 平台採用**三層北極星指標**：

| 層級 | 指標 | 說明 |
|------|------|------|
| **業務健康** | NGR MoM 增長率 | 反映整體業務可持續性 |
| **玩家健康** | MAU × ARPPU | 玩家規模 × 玩家價值 |
| **運營健康** | 支付成功率 × 系統可用性 | 基礎設施可靠度 |

**目標**：NGR 月環比增長 ≥ 5%，MAU 月環比增長 ≥ 3%。

## 2. 財務指標看板

### 2.1 每日財務指標

| 指標名稱 | 計算來源 | 警告閾值 | 緊急閾值 |
|---------|---------|---------|---------|
| 當日 GGR | 即時交易彙總 | < 前 7 日均值 × 70% | < 前 7 日均值 × 50% |
| 當日 NGR 利潤率 | NGR / GGR | < 60% | < 40% |
| 存款金額 | 已確認存款彙總 | < 前 7 日均值 × 70% | < 前 7 日均值 × 50% |
| 存款成功率 | 成功 / 發起 | < 90% | < 80% |
| 提款成功率 | 成功 / 申請 | < 95% | < 90% |

### 2.2 PSP 績效指標

| 指標 | 定義 | 優化目標 |
|------|------|---------|
| PSP 通過率（Approval Rate） | 成功授權 / 發起交易 | ≥ 85% 每個 PSP |
| PSP 處理費率 | PSP 手續費 / 交易金額 | 依協議設定上限 |
| PSP 多元化比例 | 最大單一 PSP 流量占比 | ≤ 40%（風險控制） |

## 3. 玩家生命週期指標

### 3.1 獲客漏斗（Acquisition Funnel）

```
訪客 (Visitors)
    ↓ 轉化率目標 ≥ 3%
已註冊 (Registered)
    ↓ 轉化率目標 ≥ 30%
首次存款 (First Deposit / FTD)
    ↓ 轉化率目標 ≥ 60%
活躍玩家 (Active Players)
    ↓ 轉化率目標 ≥ 15%
高價值玩家 (VIP Players)
```

### 3.2 VIP 升級指標

| VIP 等級 | 升級條件（參考） | 預期比例 |
|---------|----------------|---------|
| Bronze | 累計存款 ≥ $100 | ~40% 玩家 |
| Silver | 累計有效投注額 ≥ $5,000 | ~25% 玩家 |
| Gold | 累計有效投注額 ≥ $20,000 | ~10% 玩家 |
| Platinum | 累計有效投注額 ≥ $100,000 | ~3% 玩家 |
| Diamond | 邀請制，由 VIP 團隊管理 | < 1% 玩家 |

> **XREF**: VIP 系統詳細規則見 [促銷需求](../04_Promotions_VIP/03_Promotion_Requirements.md)

### 3.3 玩家健康指標

| 指標 | 定義 | 閾值 |
|------|------|------|
| 自我排除比例 | 主動申請自我排除的玩家比例 | 監控趨勢；突增需調查 |
| 問題賭博風險評分（均值） | 風險引擎評分均值 | > 30 觸發關懷流程 |
| 負擔能力檢查覆蓋率 | 完成負擔能力評估的高風險玩家比例 | ≥ 95%（合規要求） |

> **XREF**: 負責任賭博指標見 [負責任賭博需求](../15_Responsible_Gambling/)

## 4. 遊戲績效指標

### 4.1 遊戲組合指標

| 指標 | 計算方式 | 用途 |
|------|---------|------|
| 遊戲活躍率 | 有至少 1 次遊戲的活躍遊戲數 / 總上架遊戲數 | 判斷目錄健康度 |
| Top 10 遊戲 GGR 集中度 | Top 10 遊戲 GGR / 總 GGR | > 50% 表示過度集中 |
| 新遊戲導入成功率 | 上架後 30 日有活躍玩家的遊戲比例 | ≥ 70% |
| 遊戲供應商多元化 | 最大單一供應商 GGR 占比 | ≤ 30% |

### 4.2 體育投注指標（若適用）

| 指標 | 說明 |
|------|------|
| Margin（保留率） | 體育投注 GGR / 總投注額；目標 5-8% |
| 投注決策速度 | 賠率更新延遲；目標 < 500ms |
| 盤口暴露 | 單一賽事最大淨暴露；需設定上限 |

## 5. 風控與合規指標

### 5.1 AML 合規指標

| 指標 | 定義 | 監管要求 |
|------|------|---------|
| SAR（可疑活動報告）提交率 | 月度 SAR 提交數 | 依 MGA/UKGC 要求 |
| 大額交易報告（CTR） | 單筆超過閾值的交易 | GBP 10,000（英國） |
| KYC 增強盡職調查（EDD）覆蓋率 | 高風險玩家完成 EDD 比例 | 100% 合規要求 |

### 5.2 欺詐防控績效

| 指標 | 目標 |
|------|------|
| 自動欺詐攔截率 | ≥ 80%（減少人工介入） |
| 誤報率（False Positive） | < 5%（避免正常玩家被攔截） |
| 欺詐案例平均損失 | 持續下降趨勢 |
| 欺詐偵測延遲 | < 2 秒（即時攔截） |

## 6. 租戶指標（Multi-Tenant）

| 指標 | 說明 |
|------|------|
| 租戶 GGR 貢獻度 | 各租戶 GGR 占平台總 GGR 比例 |
| 租戶玩家增長率 | 各租戶 MAU 月環比增長 |
| 租戶保留率 | 合約到期後續簽的租戶比例 |
| 跨租戶風控事件 | 涉及多個租戶的欺詐事件數（應趨近 0） |
