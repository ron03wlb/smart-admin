# iGaming 核心 KPI 定義

> **受眾（Audience）**: 高階主管、產品經理、分析師
> **文件類型**: 業務需求 - KPI 定義與計算標準
> **XREF**: 詳細報表需求見 [報表需求](../08_Analytics_Operations/01_Reporting_Requirements.md) | BI 儀表板見 [BI 需求](../08_Analytics_Operations/02_BI_Dashboard_Requirements.md)
> **最後更新**: 2026-03-31

## 概覽

本文件定義 iGaming 平台的**核心業務 KPI（Key Performance Indicators）**，作為所有報表、儀表板、目標設定的 SSOT。

### KPI 分類架構

```
iGaming KPIs
├── 財務 KPI (Financial KPIs)
│   ├── GGR / NGR
│   ├── 存款/提款指標
│   └── PSP 成本指標
├── 玩家 KPI (Player KPIs)
│   ├── 活躍度指標 (DAU/MAU/WAU)
│   ├── 留存率指標 (Retention/Churn)
│   └── 生命週期價值 (LTV)
├── 遊戲 KPI (Gaming KPIs)
│   ├── 有效投注額 (Valid Turnover)
│   ├── RTP 指標
│   └── 遊戲覆蓋率
├── 風控 KPI (Risk KPIs)
│   ├── 欺詐率
│   ├── KYC 通過率
│   └── 爭議率
└── 運營 KPI (Operational KPIs)
    ├── 系統可用性
    ├── 支付成功率
    └── 客服 SLA
```

## 1. 財務 KPI

### 1.1 GGR（Gross Gaming Revenue，總遊戲收入）

| 項目 | 說明 |
|------|------|
| **定義** | 玩家總投注額減去總派彩 |
| **公式** | `GGR = 總投注額 (Total Bets) - 總派彩額 (Total Payouts)` |
| **計算週期** | 每小時更新（T+0，5 分鐘延遲） |
| **分解維度** | 遊戲類型（老虎機/真人/體育）、租戶、時間段 |
| **目標** | 依各租戶商業計劃設定 |

### 1.2 NGR（Net Gaming Revenue，淨遊戲收入）

| 項目 | 說明 |
|------|------|
| **定義** | GGR 扣除紅利成本、退款後的淨收入 |
| **公式** | `NGR = GGR - 紅利成本 (Bonus Cost) - 退款 (Chargebacks) - 稅費 (Taxes)` |
| **計算週期** | 每日更新（T+1） |
| **目標利潤率** | NGR/GGR ≥ 70%（業界標準） |

### 1.3 存款指標

| KPI | 公式 | 目標 |
|-----|------|------|
| 總存款額 | Sum of all confirmed deposits | 依商業計劃 |
| 首存轉化率 | 首存玩家數 / 新註冊玩家數 | ≥ 30% |
| 平均存款金額 | 總存款額 / 存款筆數 | 依市場 |
| 存款成功率 | 成功存款筆數 / 發起存款筆數 | ≥ 95% |

### 1.4 提款指標

| KPI | 公式 | 目標 |
|-----|------|------|
| 提款成功率 | 成功提款筆數 / 申請提款筆數 | ≥ 98% |
| 提款處理時間（P95） | 95% 提款的完成時間 | ≤ 24 小時 |
| 存提比（D/W Ratio） | 存款額 / 提款額 | > 1.2（健康指標） |

## 2. 玩家 KPI

### 2.1 活躍度指標

| KPI | 定義 | 計算公式 |
|-----|------|---------|
| **DAU** | Daily Active Users — 每日活躍玩家 | 當日至少有 1 次遊戲行為的唯一玩家數 |
| **WAU** | Weekly Active Users — 每週活躍玩家 | 過去 7 天至少有 1 次遊戲行為的唯一玩家數 |
| **MAU** | Monthly Active Users — 每月活躍玩家 | 過去 30 天至少有 1 次遊戲行為的唯一玩家數 |
| **DAU/MAU 比** | 日活躍度比率 | DAU / MAU × 100%；> 20% 為健康指標 |
| **付費玩家數** | 有存款行為的活躍玩家 | 當期有成功存款的唯一玩家數 |

### 2.2 留存率指標

| KPI | 定義 | 公式 |
|-----|------|------|
| **D1 留存率** | 次日留存 | 第 2 天仍活躍 / 第 1 天新玩家 × 100% |
| **D7 留存率** | 7 日留存 | 第 8 天仍活躍 / 第 1 天新玩家 × 100% |
| **D30 留存率** | 30 日留存 | 第 31 天仍活躍 / 第 1 天新玩家 × 100% |
| **月流失率（Churn Rate）** | 停止活躍的玩家比例 | (上月活躍 - 本月活躍) / 上月活躍 × 100% |

**業界參考標準**：
- D1 留存率 ≥ 40%
- D7 留存率 ≥ 20%
- D30 留存率 ≥ 10%

### 2.3 生命週期價值

| KPI | 定義 | 公式 |
|-----|------|------|
| **ARPU** | 每用戶平均收入 | NGR / MAU |
| **ARPPU** | 每付費用戶平均收入 | NGR / 付費玩家數 |
| **LTV** | 玩家生命週期價值 | ARPPU × 平均活躍月數 |
| **CAC** | 用戶獲取成本 | 行銷總支出 / 新付費玩家數 |
| **LTV:CAC 比** | 盈利健康指標 | LTV / CAC；> 3 為健康 |

## 3. 遊戲 KPI

### 3.1 有效投注額（Valid Turnover）

> **XREF**: 詳細計算規則見 [投注額業務規則](../03_Gaming_Operations/01_Turnover_Business_Rules.md)

| 項目 | 說明 |
|------|------|
| **定義** | 符合流水要求計算條件的投注額（排除無效投注） |
| **用途** | 紅利流水達標計算、VIP 等級計算 |
| **關鍵規則** | 不同遊戲類型有不同的權重係數（老虎機 100%、真人 10-20%） |

### 3.2 RTP 指標

| KPI | 定義 |
|-----|------|
| **理論 RTP** | 遊戲供應商公佈的理論回報率 |
| **實際 RTP** | 派彩額 / 投注額 × 100% |
| **RTP 偏差** | |實際 RTP - 理論 RTP|；> 5% 需調查 |

## 4. 風控 KPI

### 4.1 欺詐指標

| KPI | 定義 | 目標 |
|-----|------|------|
| 欺詐率（Fraud Rate） | 確認欺詐筆數 / 總交易筆數 | < 0.1% |
| 多帳號檢測率 | 識別的多帳號案例 / 月 | 依風險等級 |
| 爭議率（Chargeback Rate） | 爭議筆數 / 存款筆數 | < 0.5%（Visa/MC 要求） |

### 4.2 KYC 指標

| KPI | 定義 | 目標 |
|-----|------|------|
| KYC 通過率 | 首次提交通過 / 總 KYC 請求 | ≥ 80% |
| KYC 平均處理時間 | 從提交到核准的平均時間 | 自動 < 1 分鐘；人工 < 24 小時 |
| Level 2 完成率 | 完成 Level 2 KYC 的玩家比例 | ≥ 60%（高價值玩家） |

## 5. 運營 KPI

| KPI | 定義 | 目標（SLA） |
|-----|------|------------|
| 系統可用性 | (總時間 - 宕機時間) / 總時間 | ≥ 99.9% |
| API 響應時間（P95） | 95% API 請求的響應時間 | < 200ms |
| 支付成功率 | 成功支付 / 發起支付 | ≥ 95% |
| 首次聯繫解決率（FCR） | 首次接觸解決的客服工單 | ≥ 75% |
| 客服平均響應時間 | 工單從建立到首次回覆 | Live Chat < 2 分鐘；Email < 4 小時 |

## 6. KPI 審查週期

| 週期 | KPI 類型 | 負責人 |
|------|---------|--------|
| 每日 | 財務指標（GGR/NGR）、活躍度（DAU） | 運營主管 |
| 每週 | 留存率、欺詐率、遊戲績效 | 產品經理 |
| 每月 | LTV、CAC、RTP 偏差、KYC 完成率 | 高階主管 |
| 每季 | LTV:CAC 趨勢、市場份額、合規指標 | C-Level |
