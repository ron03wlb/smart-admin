# 第 9 章：分析與報表

---

## 9.1 模組概述

分析與報表模組提供全平台的數據洞察，涵蓋即時儀表板、定期報表、合規報告。系統須支援多角色差異化存取，並在數據時效性與準確性之間取得平衡。

**核心職責**: 角色化儀表板、多時效數據路徑、報表分類、合規報告、數據匯出

---

## 9.2 數據時效性分層

### 三路數據路徑

| 路徑 | 延遲 | 準確性 | 用途 |
|------|------|--------|------|
| **Hot Path** (即時) | ≤ 5 秒 | 95% | 即時監控儀表板 |
| **Warm Path** (近即時) | 5–60 秒 | 98% | 營運報表 |
| **Cold Path** (批次) | T+1 | 100% | 財務、合規報告 |

**報表延遲 SLA 分級**:

| 類別 | 最大延遲 | 適用報表 |
|------|---------|---------|
| 即時 | ≤ 5 秒 | 即時儀表板、風控監控、餘額查詢 |
| 準即時 | ≤ 1 分鐘 | 營運報表、活動監控、客服 360° 視圖 |
| 批次 | ≤ 1 小時 | GGR/NGR 小時報、遊戲表現 |
| 日結 | T+1 (次日 06:00 前可用) | 財務日報、合規日報、佣金計算 |

### 報告 SLA

| 報告類型 | 更新頻率 | 可用性目標 |
|---------|---------|----------|
| 即時儀表板 | < 5 秒 | 99.9% |
| 日報 | T+1 | 99.5% |
| 週報 | T+7 | 99.5% |
| 合規月報 | T+30 | 99% |

## 9.5 數據匯出

### 匯出格式

| 格式 | 適用場景 |
|------|---------|
| Excel (.xlsx) | 財務分析、自訂報表 |
| PDF | 正式報告、合規報告 |
| CSV | 數據整合、ETL |

### 匯出限制

| 限制 | 規則 |
|------|------|
| 小型報表 | < 100,000 行：同步匯出 |
| 大型報表 | ≥ 100,000 行：異步處理 + 下載通知 |
| API 速率 | 10 次/用戶/分鐘 |
| 租戶速率 | 100 次/租戶/分鐘 |
| 併發匯出 | 每用戶最多 5 個同時匯出 |

## 9.8 報表數據修正流程

| 步驟 | 說明 | 負責人 |
|------|------|--------|
| 1 | 發現數據異常（自動偵測或人工發現） | 系統 / BI 團隊 |
| 2 | 建立修正工單 + 影響範圍評估 | BI 團隊 |
| 3 | 追溯修正（重跑 ETL Pipeline 或手動調整） | BI 工程師 |
| 4 | 修正後報表標記「已修正」+修正時間 | 系統 |
| 5 | 合規報表修正須 CFO 審批 | CFO |
| 6 | 已對外發布的合規報表修正須通知監管機構 | 合規經理 |

**規則**: 修正記錄保留原始值與修正值，不可覆蓋原始數據（審計要求）。

### 修正對已提交監管報告的影響

> v2.2 新增 — GAP-8（報表修正對已提交監管報告影響）
> ⏳ 部分規則待合規團隊確認

| 步驟 | 動作 | 負責人 |
|------|------|--------|
| 1 | 修正觸發時，系統自動檢查該數據是否包含在已提交的監管報告中 | 系統 |
| 2 | 若涉及已提交報告 → 自動標記 `REGULATORY_IMPACT` | 系統 |
| 3 | 重要性評估: 修正值 ≤ 0.1% 報告值 → 僅記錄; > 0.1% → 強制通知監管機構 | 合規經理 |
| 4 | 生成正式修正通知（原始值 vs 修正值 + 影響說明） | 系統 + 合規經理 |
| 5 | 重大修正須在 5 個工作日內通知監管機構 | 合規經理 |
| 6 | 完整審計鏈: 原始報告 → 修正觸發 → 修正報告 → 監管通知 | 系統 |

**重要性閾值** (⏳ 待合規確認具體閾值):
- GGR/NGR 修正 > 0.1% → 通知
- 玩家數修正 > 1% → 通知
- AML/SAR 相關修正 → **一律通知**（零閾值）

## 9.9 合規報表自動化等級

| 報表 | 自動化等級 | 說明 | 人工介入 |
|------|----------|------|---------|
| GGR/NGR 日報 | **全自動** | 系統自動計算 + 生成 + 歸檔 | 僅異常時審查 |
| MGA 月度監管報表 | **半自動** | 系統自動填充數據，合規經理審核後提交 | 審核 + 簽章 + 提交 |
| UKGC SAR 統計 | **半自動** | 系統自動彙總 SAR 數據，MLRO 審核 | MLRO 審核 + 提交 |
| AML/KYC 月度指標 | **全自動** | 自動計算各指標 + 生成趨勢報告 | 僅異常閾值觸發審查 |
| 負責任博彩月報 | **半自動** | 自動彙總自我排除、限額數據 | 合規經理審核 + 提交 |
| 年度 PCI-DSS 合規報告 | **手動** | QSA 第三方稽核，系統提供數據匯出 | 全程手動配合稽核 |
| 稅務報表 | **半自動** | 系統計算稅基，CFO 審核後提交 | CFO 審核 + 會計師簽章 |
| GDPR 刪除統計 | **全自動** | 自動追蹤刪除請求生命週期 + 月度統計 | 僅年度審計時審查 |

**自動化等級定義**:
- **全自動**: 系統端到端完成，無需人工介入。異常時自動告警。
- **半自動**: 系統產生初版，需指定人員審核後提交。
- **手動**: 需人工主導，系統僅提供數據支持。
