# 第 15 章：負責任博彩

---

## 15.1 模組概述

負責任博彩模組是合規營運的基石，確保平台符合各管轄區的玩家保護法規。涵蓋自我排除、存款限額、損失限額、Session 保護、可負擔性評估。

**核心職責**: 自我排除、限額管理、冷靜期、現實檢查、可負擔性評估、行銷限制

---

## 15.2 自我排除

### 全球自我排除資料庫

| 管轄區 | 資料庫 | 要求 |
|--------|--------|------|
| 英國 | GAMSTOP | UKGC 牌照強制 |
| 荷蘭 | CRUKS | KOA 強制 |
| 瑞典 | Spelpaus | 瑞典牌照強制 |
| 丹麥 | ROFUS | 丹麥牌照強制 |
| 馬爾他 | MGA 登記冊 | 多營運商國家登記 |

### 排除類型

| 類型 | 期限 | 撤銷 | 冷靜期 |
|------|------|------|--------|
| 臨時 | 24 小時–6 週 | 自動到期 | — |
| 中期 | 6 個月–1 年 | 需申請 + 冷靜期 | 1–7 天 |
| 永久 | 終身 | **不可撤銷** | — |

### 啟動流程

1. 玩家提交排除請求 (確認對話框)
2. ≥ 6 個月: 24 小時冷靜期
3. ≤ 30 天: 立即啟動
4. 啟動時:
   - 關閉所有活動 Session 與遊戲
   - 結算待處理投注與紅利
   - 同步至國家資料庫 (GAMSTOP/CRUKS 等)
   - 發送確認通知

### 排除生效時 Token 與 Session 撤銷

| 步驟 | 動作 | 時限 |
|------|------|------|
| 1 | 撤銷所有活躍 GP Token（廣播至所有已連接 GP） | 即時 |
| 2 | 通知所有 GP 該玩家已排除（GP 須拒絕後續請求） | ≤ 30 秒 |
| 3 | 等待進行中回合結算（GP 須在 5 分鐘內完成結算或回滾） | ≤ 5 分鐘 |
| 4 | 未在 5 分鐘內結算的回合 → 強制回滾 + 退還投注金額 | 自動 |
| 5 | 凍結所有錢包（CASH / BONUS / CREDIT） | 即時 |
| 6 | 代理信用投注管道同步封鎖（見 Ch8） | 即時 |

**關鍵規則**: 排除檢查必須覆蓋所有投注管道 — 直接投注、代理信用投注、代理代操作。任何管道的遺漏均視為合規違規。

### 排除期間限制

| 允許 | 禁止 |
|------|------|
| 查看餘額 | 存款 |
| 查看投注歷史 | 遊戲 |
| 聯繫客服 | 投注 |
| 提款自有資金（CASH 錢包） | 領取紅利 |
| — | 接收行銷訊息 |
| — | 代理信用投注 |
| — | 透過任何管道下注 |

### 反規避偵測

- 設備指紋匹配
- 支付方式匹配
- IP 地址追蹤
- 重新註冊嘗試偵測
- 目標: 規避率 < 5%
- GAMSTOP 同步成功率: > 99.9%

### GAMSTOP 匹配超時預設行為

> v2.2 新增 — GAP-7（GAMSTOP 70%+ 相似度匹配超時處理）

**問題**: GAMSTOP 回傳 70%+ 相似度匹配時，系統設置 24 小時 hold 等待人工審核。但若審核未在 24 小時內完成，預設行為未定義。

| 時間點 | 處理方式 |
|--------|---------|
| 0–24 小時 | 帳戶 hold，等待人工審核（已定義） |
| 24 小時未完成 | **維持 hold**（絕不自動放行）+ 升級至合規經理 + 發送警報 |
| 48 小時未完成 | 升級至 MLRO + 帳戶升級為 SUSPENDED |
| 72 小時未完成 | 強制觸發帳戶凍結 + 監管事件報告 |

**核心規則**:
- **禁止自動放行**: GAMSTOP 匹配永遠不可因超時而自動解除 hold（監管風險過高）
- 審核 SLA: 95% 的 GAMSTOP 人工審核須在 24 小時內完成
- 審核結果: 確認為同一人 → 啟動自我排除流程；確認非同一人 → 解除 hold + 記錄審核依據

## 15.3 存款限額

### 法規要求

| 管轄區 | 要求 | 預設值 |
|--------|------|--------|
| 英國 (UKGC) | 2025-10-31 起首存前強制設定 | 無預設 (玩家自定) |
| 德國 | 每月 €1,000 硬性上限 | €1,000 (不可覆蓋) |
| 荷蘭 | 建議設定 | €200/日, €700/週, €2,000/月 |

### 限額類型

| 類型 | 說明 |
|------|------|
| 每日限額 | 24 小時內存款上限 |
| 每週限額 | 7 天內存款上限 |
| 每月限額 | 30 天內存款上限 |

### 調整規則

| 操作 | 生效時間 | 冷靜期 |
|------|---------|--------|
| **降低**限額 | 立即生效 | 無 |
| **提高**限額 | 24–72 小時延遲 | 有 (玩家可取消) |
| **移除**限額 | 同提高 (需冷靜期) | 24–72 小時 |

### 層級驗證

- 強制: 每日 ≤ 每週 ≤ 每月
- 檢查順序: 每日 → 每週 → 每月
- 違反層級規則 → 系統拒絕設定

## 15.4 損失限額

### 損失計算

```
淨損失 = 總投注 - 總派彩
```

| 對比項 | 存款限額 | 損失限額 |
|--------|---------|---------|
| 基礎 | 存入金額 | 淨損失 |
| 目的 | 控制投入 | 控制實際損失 |
| 贏錢影響 | 不影響 | 減少累計損失 (可重新投注) |

### 觸發行為

- 達到 80% → 發送預警通知
- 達到 100% → 顯示「限額已達」+ 剩餘金額
- 系統零容忍: 不允許系統導致的限額突破

## 15.5 Session 保護

### 冷靜期 (Time-Out)

| 時長 | 用途 | 結束方式 |
|------|------|---------|
| 24 小時 | 每日冷靜 | 自動恢復 |
| 48 小時 | 週末休息 | 自動恢復 |
| 72 小時 | 3 天冷靜 | 自動恢復 |
| 7 天 | 每週休息 | 自動恢復 |
| 14 天 | 兩週休息 | 自動恢復 |
| 30 天 | 月度休息 | 自動恢復 |
| 6 週 | 最長冷靜 | 自動恢復 |

**冷靜期 vs 自我排除**:
- 冷靜期: 預防性、短期、可逆
- 自我排除: 干預性、長期、通常不可逆

### 強制休息

| 管轄區 | 規則 |
|--------|------|
| UKGC | 24 小時內 10 次存款 → 60 分鐘強制休息 |
| 德國 | 連續遊戲 60 分鐘 → 5 分鐘強制休息 |
| 瑞典 | 提供 Session 限制選項 (15/30/60/120 分鐘) |

### 現實檢查 (Reality Check)

| 項目 | 規則 |
|------|------|
| 間隔 | 可配置: 15 / 30 / 60 分鐘 (或關閉) |
| 顯示內容 | Session 時長 + 淨盈虧 (虧損顯示為負數) |
| 玩家選項 | 繼續 / 停止 / 設定限額 / 查看歷史 |
| 自動旋轉 | 觸發時暫停 |
| 活動回合 | 等待當前回合完成後顯示 |

### 閒置登出

| 項目 | 規則 |
|------|------|
| 預設 | 30 分鐘無操作 → 自動登出 |
| 可配置 | 15–60 分鐘 |
| 活動回合 | 排除在閒置計算外 |

### 風險行為偵測

| 行為 | 觸發動作 |
|------|---------|
| 10+ 次快速略過現實檢查 (< 5 秒) | 建議提高檢查頻率 |
| Session > 4 小時 | 發送關懷訊息 |
| 虧損 > 存款 50% 仍繼續 | 觸發可負擔性評估 |
| 累計虧損 > $1,000 仍繼續 | 建議設定限額 |

## 15.6 可負擔性評估 (UKGC 2025)

### 三級評估框架

| 級別 | 觸發條件 | 評估方式 | 內容 |
|------|---------|---------|------|
| **Basic** | 淨損失 £125–£500 | 警告訊息 | 告知玩家 |
| **Enhanced** | 淨損失 £500–£2,000 | 自我聲明 | 收入、住房、受撫養人、可支配收入 |
| **Full** | 淨損失 > £2,000 | 第三方驗證 | Open Banking + 信用機構 + 公開記錄 |

### 額外觸發 (2025-02-28 新規)

- 30 天滾動淨存款 ≥ £150 → 財務脆弱性檢查

### 評估有效期

| 級別 | 有效期 |
|------|--------|
| Basic | 3 個月 |
| Enhanced | 6 個月 |
| Full | 12 個月 |

到期自動觸發重新評估。

### 建議限額計算

- 最大安全消費 = 可支配收入 × 10%
- 家庭人數 > 2: 減少 20%
- 下限: £50
- 上限: £2,000

### 評估結果決策框架

| 結果 | 處置 | 具體行動 |
|------|------|---------|
| **PASSED** | 無干預 | 記錄評估結果，設定下次重評日期 |
| **FAILED — Basic** | 強制提示 | 顯示可負擔性警告訊息 + 建議設定限額 |
| **FAILED — Enhanced** | 降低限額 | 存款限額降至自我聲明可支配收入 × 10%，損失限額同步調整 |
| **FAILED — Full** | 嚴格限制 | 存款限額降至第三方驗證可支配收入 × 10%，超過 £2,000 須 MLRO 審批 |
| **DECLINED（拒絕提供資料）** | 預防性限制 | 套用管轄區最低預設限額 + 標記人工審核（24 小時內完成） |
| **TIMEOUT（超過 7 天未完成）** | 暫停存款 | 暫停存款功能直到評估完成，允許繼續遊戲與提款 |

### 人工介入觸發條件

| 條件 | 動作 |
|------|------|
| Enhanced 評估自我聲明異常（收入極高或極低） | 標記人工審核 |
| Full 評估第三方數據不一致 | 升級至 MLRO |
| 玩家行為與聲明不符（如聲明低收入但持續大額存款） | 自動觸發 Full 評估 |
| 連續 3 次 FAILED | 強制 14 天冷靜期 + MLRO 審查 |

### 評估超時期間的遊戲中處理

> v2.2 新增 — GAP-6（可負擔性評估超時期間遊戲中玩家處理）

**問題**: §15.6 定義 TIMEOUT 後「暫停存款功能」，但未定義正在遊戲中的玩家如何處理。

| 場景 | 處理方式 |
|------|---------|
| 玩家正在進行遊戲回合 | 允許當前回合自然完成（不中斷） |
| 當前回合結束後 | 禁止新投注，顯示「可負擔性評估待完成」訊息 |
| 存款功能 | 暫停（已定義） |
| 提款功能 | **允許** — 保護玩家資金權益 |
| 帳戶查詢 | 允許查看餘額、投注歷史、聯繫客服 |
| 紅利流水計時器 | 暫停計時（評估完成後恢復） |
| 評估完成或玩家提供資料後 | 即時恢復全部功能 |

**關鍵原則**: 超時處理以保護玩家為優先 — 不因系統流程中斷正在進行的遊戲，但嚴格防止新的風險暴露。

## 15.7 行銷限制

### 排除/冷靜期間

| 規則 | 說明 |
|------|------|
| 禁止推廣 | 無促銷 Email、SMS、推送通知 |
| 禁止特殊優惠 | 無紅利、VIP 邀請 |
| 禁止再行銷 | 無重定向廣告 |
| DND 旗標 | 自動設定，批次任務跳過 |
| 違規偵測 | 若排除玩家收到行銷 → 警報 |
