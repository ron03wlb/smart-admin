## 📋 模塊職責

本模塊涵蓋玩家資金流動的完整生命週期，從註冊到充值、遊戲、出金的全流程。

**核心內容**：
- 玩家生命週期管理
- 錢包架構（**SSOT: 可下注餘額公式**）
- 支付整合
- 交易處理流程
- 出金風控
- 對帳系統

**職責邊界**：
- ✅ 包含：資金流動邏輯、錢包模型、支付對接
- ❌ 不包含：遊戲技術細節（在 02_Game_Operations）
