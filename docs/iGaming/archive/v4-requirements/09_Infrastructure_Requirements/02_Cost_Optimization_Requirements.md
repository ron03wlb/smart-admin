## 業務價值（Business Value）

此基礎設施成本優化計畫通過以下方式提供價值：
- **直接成本節省**：將月度基礎設施成本降低 37%（從 $2,820 降至 $1,788），實現年度淨節省 $12,383，6 個月投資回收期
- **效能提升**：同步將系統容量提升 418%（>450 TPS）並將 P99 延遲降低 84%（<200ms），證明成本降低與效能提升可以並行
- **營運自主性**：通過遷移至自建開源方案消除外部監控服務依賴，實現外部監控成本 100% 消除，同時維持完整可觀察性（指標、日誌、追蹤、告警）
- **資料生命週期管理**：基於存取模式實施分層存儲策略（熱/暖/冷/歸檔），存儲成本降低 94%，同時維持適當的查詢 SLA（0-2 個月 50ms，20+ 個月最長 12 小時）
- **可擴展性基礎**：引入運算資源自動擴縮機制和專用分析引擎查詢分流，支撐業務增長而無需等比例增加成本

## 業務背景

隨著平台業務增長，基礎設施成本持續攀升。需要在不降低系統效能和可用性的前提下，系統性地優化各項基礎設施支出，實現「效能提升與成本降低並行」的目標。

---

## 核心業務需求

### 1. 整體成本目標

| 指標 | 目標 |
|------|------|
| **月度成本節省** | 降低 37%（從 $2,820 降至 $1,788） |
| **年度淨節省** | $12,383 |
| **投資回收期** | 6 個月內 |
| **效能同步提升** | 處理能力提升 4 倍以上，回應時間降低 84% |

### 2. 存儲成本優化

**業務需求**: 不同時效的資料應使用不同成本等級的存儲方式

| 資料類型 | 存取頻率 | 查詢時效需求 | 成本目標 |
|---------|---------|------------|---------|
| **近期資料**（0-2 個月） | 高頻即時查詢 | < 50 毫秒 | 適用高速存儲 |
| **中期資料**（3-6 個月） | 偶爾查詢（客服使用） | 2-5 秒 | 適用標準存儲 |
| **歷史資料**（7-19 個月） | 低頻查詢（運營分析） | 1-5 分鐘 | 適用低成本存儲 |
| **歸檔資料**（20+ 個月） | 極少查詢（審計法務） | 12 小時 | 適用最低成本存儲 |

**目標節省率**: 存儲成本降低 94%

### 3. 訊息管線優化

| 需求 | 說明 |
|------|------|
| **保留策略調整** | 訊息管線僅保留 7 天即時處理所需資料，長期資料另行存放 |
| **節省目標** | 訊息管線存儲成本降低 76% |

### 4. 運算資源優化

| 需求 | 說明 |
|------|------|
| **查詢分流** | 複雜聚合報表查詢從主要資料庫分流至專用分析引擎 |
| **資料庫降級** | 主要資料庫負載降低 50% 後，可使用較小規格的實例 |
| **快取層優化** | 透過進程內快取降低 90% 的分散式快取訪問量，進而使用較小規格實例 |
| **自動擴縮** | 非高峰時段自動縮減運算資源，高峰時段自動擴展 |

### 5. 監控成本優化

| 需求 | 說明 |
|------|------|
| **去除外部依賴** | 從付費監控服務遷移至自建開源方案 |
| **監控功能完整** | 遷移後須涵蓋指標監控、日誌管理、鏈路追蹤、告警管理 |
| **外部成本節省** | 100%（外部監控費用歸零） |

### 6. 成本可視化與告警

| 需求 | 說明 |
|------|------|
| **月度成本儀表板** | 可視化各服務的成本趨勢 |
| **成本異常偵測** | 超出預算 10% 時自動告警 |
| **容器集群成本分析** | 各服務的成本分攤、資源使用率、閒置資源偵測 |
