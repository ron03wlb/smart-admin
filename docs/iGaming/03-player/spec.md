## 2. Domain Context

### 為何這三章合為一個 split

玩家管理是**所有業務流程的入口** — 下游模組（錢包、遊戲、促銷、風控）皆依賴玩家資料作為決策基礎。負責任博彩（Ch15）的自我排除、限額、可負擔性評估都是玩家狀態的延伸，直接操作玩家生命週期狀態機。客戶服務（Ch12）的 360° 視圖以玩家為核心聚合所有數據，AI Chatbot 和工單系統的路由也依賴玩家 VIP 等級和標籤。三者共享玩家實體，合為一域可避免跨域循環依賴。

### 依賴關係

```
01-governance-agent ──→ 03-player (tenant_id, RBAC)
03-player ──→ 04-gaming (Player Token, KYC 狀態)
03-player ──→ 05-risk-compliance (玩家資料, 標籤)
03-player ──→ 06-frontend-integration (玩家 API)
03-player ──→ 07-data-infrastructure (玩家行為數據)
```

- **上游依賴**: 僅 `01-governance-agent`（tenant_id 隔離、RBAC 權限體系）
- **可平行**: 與 `02-funding` 同時開發（兩者皆僅依賴 01）
- **下游消費者**: 04-gaming、05-risk-compliance、06-frontend、07-data

## 3. SSOT Boundary — 本域持有

本域為以下概念的**唯一真相來源**，其他域須引用本域、不得重複定義。

### 3.1 KYC 四級驗證規則 (SSOT: Ch1 §1.4)

四級體系 L0→L3，每級定義驗證要求、存提款限額、觸發條件、自動審批規則。

| 級別 | 驗證要求 | 提款限額 | 存款限額 | 觸發條件 |
|------|---------|---------|---------|---------|
| **L0** | Email 或手機驗證 | 禁止提款 | $500/日 | 註冊即觸發 |
| **L1** | 姓名 + 政府證件號碼 + 出生日期 | $1,000/日 | $5,000/日 | 首次存款或首次提款申請 |
| **L2** | L1 + 地址證明 (3 個月內) + 證件照片 | $10,000/日 | $50,000/日 | 累計存款 > $2,000 或提款 > $1,000 |
| **L3** | L2 + 銀行帳戶驗證 + 資金來源聲明 | 無限制 | 無限制 | 累計存款 > $10,000 或 VIP Gold 以上 |

**司法管轄區差異**:

| 牌照 | 額外要求 | 提款觸發 KYC |
|------|---------|------------|
| UKGC | L1 必須在**首存前**完成；72 小時內完成 L2 否則凍結 | 任何金額 |
| MGA | L1 可延後至首次提款；90 天內完成 L2 | > EUR 2,000 累計 |
| PAGCOR | 接受菲律賓政府 ID；支援 GCash 驗證 | > PHP 50,000 累計 |
| Curacao | L1 最低要求；L2 於大額提款時 | > $2,000 單筆 |

**自動審批規則**:
- L0: Email/手機 OTP 成功 → 即時自動通過
- L1: OCR 識別 + 姓名/生日匹配 → < 30 秒自動通過；OCR 失敗 → 人工 <= 24h
- L2: 地址文件 OCR 成功 → < 1 分鐘自動通過；OCR 失敗 → 人工 <= 48h
- L3: 銀行帳戶微額轉帳 → 1-3 工作天；資金來源 → 人工 <= 72h

### 3.2 自我排除機制 (SSOT: Ch15 §15.2)

**全球資料庫對接**: GAMSTOP (UKGC)、CRUKS (荷蘭)、Spelpaus (瑞典)、ROFUS (丹麥)、MGA 登記冊

**排除類型**:

| 類型 | 期限 | 撤銷 | 冷靜期 |
|------|------|------|--------|
| 臨時 | 24h–6 週 | 自動到期 | 無 |
| 中期 | 6 個月–1 年 | 需申請 + 冷靜期 | 1–7 天 |
| 永久 | 終身 | **不可撤銷** | 無 |

**Token & Session 撤銷流程 (v2.2)**:
1. 撤銷所有活躍 GP Token（廣播至所有已連接 GP）→ 即時
2. 通知所有 GP 該玩家已排除（GP 須拒絕後續請求）→ <= 30 秒
3. 等待進行中回合結算（GP 須在 5 分鐘內完成結算或回滾）→ <= 5 分鐘
4. 未在 5 分鐘內結算 → 強制回滾 + 退還投注金額 → 自動
5. 凍結所有錢包（CASH / BONUS / CREDIT）→ 即時
6. 代理信用投注管道同步封鎖 → 即時

**排除期間權限**:
- 允許: 查看餘額、查看投注歷史、聯繫客服、提款自有資金 (CASH)
- 禁止: 存款、遊戲、投注、領取紅利、接收行銷、代理信用投注、透過任何管道下注

**反規避偵測**: 設備指紋匹配、支付方式匹配、IP 追蹤、重新註冊偵測（目標: 規避率 < 5%，GAMSTOP 同步 > 99.9%）
> 注: 設備指紋偵測演算法由 05-risk-compliance (Ch6 §6.9) 持有，本域呼叫其 API。

**GAMSTOP 匹配超時處理 (v2.2 GAP-7)**:
- 0–24h: 帳戶 hold，等待人工審核
- 24h 未完成: **維持 hold**（禁止自動放行）+ 升級至合規經理 + 警報
- 48h 未完成: 升級至 MLRO + 帳戶升級為 SUSPENDED
- 72h 未完成: 強制帳戶凍結 + 監管事件報告
- 核心規則: GAMSTOP 匹配**永遠不可**因超時而自動解除 hold

### 3.3 問題博彩預警 (SSOT: Ch15 §15.5)

六項風險指標:

| 指標 | 閾值 | 風險等級 | 觸發動作 |
|------|------|---------|---------|
| 單日存款次數 | >= 5 次 | 中 | 彈出提醒訊息 |
| 單日存款金額 | 超過月均 3 倍 | 高 | 彈出冷靜期建議 |
| 連續遊戲時長 | > 4 小時 | 中 | 強制彈出休息提醒 |
| 追損行為 (Loss Chasing) | 連續 3 次加碼投注 | 高 | 彈出自我排除選項 |
| 深夜投注頻率 | 00:00–06:00 投注 > 日均 200% | 中 | 記錄但不干預 |
| 借貸行為信號 | 多次小額存款 (快速連續) | 高 | 標記 + 客服介入 |

### 3.4 可負擔性評估 (SSOT: Ch15 §15.6)

UKGC 2025 三級框架:

| 級別 | 觸發條件 | 評估方式 | 有效期 |
|------|---------|---------|--------|
| **Basic** | 淨損失 GBP 125–500 | 警告訊息 | 3 個月 |
| **Enhanced** | 淨損失 GBP 500–2,000 | 自我聲明（收入、住房、受撫養人、可支配收入） | 6 個月 |
| **Full** | 淨損失 > GBP 2,000 | 第三方驗證（Open Banking + 信用機構 + 公開記錄） | 12 個月 |

額外觸發 (2025-02-28 新規): 30 天滾動淨存款 >= GBP 150 → 財務脆弱性檢查

**建議限額計算**: 最大安全消費 = 可支配收入 x 10%（家庭人數 > 2 減 20%；下限 GBP 50，上限 GBP 2,000）

**評估結果決策框架**:

| 結果 | 處置 |
|------|------|
| PASSED | 無干預，記錄結果，設定重評日期 |
| FAILED (Basic) | 強制顯示可負擔性警告 + 建議設定限額 |
| FAILED (Enhanced) | 存款限額降至可支配收入 x 10%，損失限額同步調整 |
| FAILED (Full) | 嚴格限制，超過 GBP 2,000 須 MLRO 審批 |
| DECLINED (拒絕提供) | 套用管轄區最低預設限額 + 24h 內人工審核 |
| TIMEOUT (超過 7 天) | 暫停存款，允許繼續遊戲與提款 |

**人工介入觸發**:
- Enhanced 自我聲明異常（收入極高或極低）→ 人工審核
- Full 第三方數據不一致 → 升級至 MLRO
- 行為與聲明不符 → 自動觸發 Full 評估
- 連續 3 次 FAILED → 強制 14 天冷靜期 + MLRO 審查

**評估超時期間遊戲中處理 (v2.2 GAP-6)**:
- 進行中回合: 允許當前回合自然完成（不中斷）
- 當前回合結束後: 禁止新投注，顯示「可負擔性評估待完成」
- 存款: 暫停
- 提款: **允許** — 保護玩家資金權益
- 紅利流水計時器: 暫停（評估完成後恢復）
- 核心原則: 不因系統流程中斷進行中遊戲，但嚴格防止新的風險暴露

## 5. Functional Requirements — Ch1 玩家管理

### 5.1 Player Lifecycle State Machine

7 狀態: `REGISTERED → ACTIVE → DORMANT → SELF_EXCLUDED → COOLING_OFF → SUSPENDED → CLOSED`

**狀態轉換規則** (完整定義見 Ch1 §1.2):
- REGISTERED → ACTIVE: 首次存款
- ACTIVE → DORMANT: 90 天無活動
- DORMANT → ACTIVE: 重新登入/存款
- ACTIVE → SELF_EXCLUDED: 玩家自我排除
- SELF_EXCLUDED → COOLING_OFF: 排除期滿
- COOLING_OFF → ACTIVE: 冷靜期滿 + 玩家確認
- ACTIVE → SUSPENDED: 風控觸發 / 管理凍結
- SUSPENDED → ACTIVE: 審核通過解凍
- SUSPENDED → CLOSED: 永久封禁
- DORMANT → CLOSED: 365 天無活動 + 零餘額
- ACTIVE → CLOSED: 玩家申請銷戶

**各狀態權限矩陣**:

| 狀態 | 允許操作 | 限制操作 |
|------|---------|---------|
| REGISTERED | 瀏覽遊戲、修改資料 | 存款（需 KYC L0）、投注、提款 |
| ACTIVE | 所有操作 | 依 KYC 等級限制提款額度 |
| DORMANT | 登入、存款 | 提款需重新驗證身份 |
| SELF_EXCLUDED | 無 | 所有操作禁止，包括登入 |
| COOLING_OFF | 查看資料 | 投注、存款禁止，需主動確認恢復 |
| SUSPENDED | 查看餘額 | 存款、投注、提款均禁止 |
| CLOSED | 無 | 無法恢復 |

### 5.2 Registration

**4 種註冊方式**:

| 方式 | 必填欄位 | 驗證要求 |
|------|---------|---------|
| Email 註冊 | Email、密碼、使用者名稱、出生日期 | Email 驗證碼 (10 min 有效) |
| 手機號註冊 | 手機號、密碼、使用者名稱、出生日期 | SMS OTP (5 min 有效) |
| 社交帳號 | OAuth (Google/Facebook/Line) | OAuth Token；需補填出生日期 |
| 一鍵註冊 | 僅手機號 | SMS OTP；後續補資料 |

**初始化規則**:
- 帳戶狀態 = `REGISTERED`
- 自動建立 CASH 錢包（餘額 = 0）
- VIP 等級 = Bronze
- 綁定品牌/租戶（不可變更）
- 記錄註冊來源（Landing Page URL、推廣碼、代理碼）
- 記錄 IP 與設備指紋

**防重複註冊**:
- 相同 Email → 拒絕
- 相同手機號 → 拒絕
- 相同設備指紋 + 不同 Email → 允許但標記風控旗標
- 同一 IP 24h 內 >= 3 次 → CAPTCHA / 人工審核

**年齡限制**: 全球最低 18 歲；美國部分州 21 歲；KYC L1 交叉驗證證件出生日期

### 5.3 KYC 4-Level Verification

> 完整 SSOT 定義見上方 §3.1

實作要點:
- 可接受文件清單（L1 身份: 護照/身分證/駕照；L2 地址: 銀行帳單/水電帳單/稅務通知/信用卡帳單；L3 資金來源: 薪資/銀行交易/投資/房產證明）
- OCR 自動識別 + 人工審核 fallback
- 多管轄區差異化配置（以 tenant 維度覆蓋）

### 5.4 VIP 5-Tier System

| 等級 | 升級門檻 (月有效投注) | 維持門檻 | 積分倍率 |
|------|---------------------|---------|---------|
| Bronze | 預設 | 無 | 1x |
| Silver | $10,000 | $5,000/月 | 1.5x |
| Gold | $50,000 | $25,000/月 | 2x |
| Platinum | $200,000 | $100,000/月 | 3x |
| Diamond | $500,000 | $250,000/月 | 5x |

**升級規則**:
- 評估週期: 每月 1 日凌晨計算上月
- 達到門檻即時升級（不等待月結）
- 升級後立即生效所有新等級福利

**降級規則**:
- 連續 2 個月未達維持門檻 → 降一級
- 降級保護期: Diamond 3 個月、Platinum 2 個月、其餘 1 個月（均可配置）
- 第 1 個月未達標 → 預警通知

**特殊規則**:
- DORMANT 不觸發降級（僅根據投注額）
- SUSPENDED 凍結 VIP 評估，解凍後繼續
- 人工升級需填寫原因 + 審計記錄

### 5.5 VIP Points

- 獲取: 每 $1 有效投注 = 1 基礎積分 x VIP 倍率
- 遊戲積分率: Slots 100%、Table Games 50%、Sports 75%
- 有效期: 365 天（滾動計算）
- 用途: 兌換現金紅利 (100 積分 = $1)、免費旋轉、VIP 商城
> 注: VIP 返水率由 04-gaming (Ch5 §5.6) 持有。

### 5.6 RFM Player Segmentation

**RFM 評分 (1-5)**:
- R (Recency): 最近活動距今天數 — 5: <=7d / 4: 8-14d / 3: 15-30d / 2: 31-60d / 1: >60d
- F (Frequency): 30 天投注次數 — 5: >=100 / 4: 50-99 / 3: 20-49 / 2: 5-19 / 1: <5
- M (Monetary): 30 天有效投注額 — 5: >=$10K / 4: $5K-$9,999 / 3: $1K-$4,999 / 2: $100-$999 / 1: <$100

**分群矩陣**:

| 分群 | RFM 範圍 | 建議策略 |
|------|---------|---------|
| Champions | R5F5M5 – R4F4M4 | VIP 維護、專屬活動 |
| Loyal | R3F4M4 – R3F3M3 | 忠誠獎勵、積分加碼 |
| Potential | R5F2M2 – R4F2M2 | 個人化推薦、首充紅利 |
| At Risk | R2F3M3 – R2F2M2 | 召回活動、限時優惠 |
| Hibernating | R1F1M1 – R1F2M1 | 大額召回紅利 |
| New Players | R5F1M1 | 新手引導、首存獎勵 |

- **更新頻率**: 每日 02:00 UTC 重新計算
- 分群變動自動觸發行銷自動化流程
- 異常跳級（如 Champions → Hibernating）觸發警示

### 5.7 Player Tag System

**系統自動標籤** (部分):

| 類別 | 標籤 | 觸發條件 | 用途 |
|------|------|---------|------|
| 風控 | `HIGH_RISK` | 風險評分 >= 70 | 提款自動拒絕 |
| 風控 | `BONUS_ABUSER` | 紅利濫用偵測命中 | 禁止領取紅利 |
| 風控 | `MULTI_ACCOUNT` | 多帳戶偵測命中 | 帳戶凍結審查 |
| 行為 | `WHALE` | 月投注 > $100K | VIP 通知 |
| 行為 | `PROBLEM_GAMBLER` | 問題博彩指標觸發 | 觸發負責任博彩介入 |
| 生命週期 | `CHURN_RISK` | RFM 降至 At Risk | 觸發召回流程 |
| 合規 | `PEP` | 政治公眾人物篩查命中 | EDD |

## 6. Functional Requirements — Ch15 負責任博彩

### 6.1 Self-Exclusion

> 完整 SSOT 定義見上方 §3.2

實作子項:
- 全球資料庫同步 (GAMSTOP/CRUKS/Spelpaus/ROFUS/MGA)
- 排除類型管理（臨時/中期/永久）
- 啟動流程: >= 6 個月需 24h 冷靜期；<= 30 天立即啟動
- Token & Session 撤銷 (v2.2)
- 排除期間權限控制
- 反規避偵測
- GAMSTOP 匹配超時處理 (v2.2 GAP-7)

### 6.2 Deposit Limits

**法規要求**:

| 管轄區 | 要求 | 預設值 |
|--------|------|--------|
| UKGC | 2025-10-31 起首存前強制設定 | 無預設 (玩家自定) |
| 德國 | 每月 EUR 1,000 硬性上限 | EUR 1,000 (不可覆蓋) |
| 荷蘭 | 建議設定 | EUR 200/日, EUR 700/週, EUR 2,000/月 |

**限額類型**: 每日 / 每週 / 每月

**調整規則**:
- 降低限額 → 立即生效
- 提高限額 → 24–72h 延遲 + 冷靜期（玩家可取消）
- 移除限額 → 同提高規則

**層級驗證**: 每日 <= 每週 <= 每月（違反則拒絕設定）

### 6.3 Loss Limits

計算公式: `淨損失 = 總投注 - 總派彩`

觸發行為:
- 達到 80% → 預警通知
- 達到 100% → 顯示「限額已達」+ 剩餘金額
- **零容忍**: 不允許系統導致的限額突破

### 6.4 Session Protection

**冷靜期 (Time-Out)**: 24h / 48h / 72h / 7d / 14d / 30d / 6 週（自動恢復）

**強制休息**:
- UKGC: 24h 內 10 次存款 → 60 min 強制休息
- 德國: 連續遊戲 60 min → 5 min 強制休息
- 瑞典: 提供 Session 限制選項 (15/30/60/120 min)

**現實檢查 (Reality Check)**:
- 間隔可配置: 15 / 30 / 60 min
- 顯示: Session 時長 + 淨盈虧
- 觸發時暫停自動旋轉；等待當前回合完成後顯示
- 玩家選項: 繼續 / 停止 / 設定限額 / 查看歷史

**閒置登出**: 預設 30 min 無操作；可配置 15–60 min；活動回合排除在閒置計算外

**風險行為偵測**:
- 10+ 次快速略過現實檢查 (< 5 秒) → 建議提高頻率
- Session > 4h → 關懷訊息
- 虧損 > 存款 50% 仍繼續 → 觸發可負擔性評估

### 6.5 Affordability Assessment

### 6.6 Marketing Restrictions

排除/冷靜期間:
- 禁止: 促銷 Email/SMS/推送、特殊優惠、紅利、VIP 邀請、再行銷/重定向廣告
