## 根因分析

### 問題 1: source-archive 污染 (影響: -9%)

`check-terminology-consistency-zh-tw.sh` v1.0 掃描整個 `docs/iGaming/` 目錄，包含 191 個 READ-ONLY 的 source-archive 英文檔案。這些檔案中的 "流水" 同時與已翻譯檔案的 "有效投注額" 共存於掃描結果中。

**修復**: v2.0 添加 source-archive/ 跳過規則（P18 guardrail）

### 問題 2: "流水" 複合術語誤報 (影響: -4%)

v1.0 腳本將 "流水" 與 "有效投注額" 的共存一律標記為不一致。但 "流水" 在以下複合術語中是合法的：

| 複合術語 | 英文 | 說明 |
|---------|------|------|
| 流水要求 | Wagering Requirement | 提款前需完成的投注倍數 |
| 流水進度 | Wagering Progress | 完成流水要求的百分比 |
| 流水計算 | Turnover Calculation | 有效投注額的計算過程 |
| 流水對帳 | Turnover Reconciliation | 投注數據與遊戲供應商對帳 |
| 流水操縱 | Turnover Manipulation | 人為操控流水的詐欺行為 |
| 流水倍數 | Wagering Multiplier | 流水要求的倍數設定 |
| 流水異常 | Turnover Anomaly | 異常投注模式 |
| 高流水 / 低流水 | High/Low Turnover | 投注量描述 |

**修復**: v2.0 添加智能排除，僅標記獨立使用的 "流水" 與 "有效投注額" 的混用

### 問題 3: 實際術語錯誤 (影響: -2%, 2 files)

| 檔案 | 錯誤 | 修復 |
|------|------|------|
