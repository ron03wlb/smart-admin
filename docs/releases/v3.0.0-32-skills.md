### 1. postgresql-best-practices (P2 - Integration)

**Location**: `productivity/integration/postgresql-best-practices/`

**Purpose**: PostgreSQL performance analysis and optimization for SmartAdmin projects

**Capabilities**:
- **HikariCP Analysis**: Connection pool utilization analysis with optimal sizing recommendations
  - Formula: `connections = (core_count × 2) + effective_spindle_count`
  - Monitors: active connections, idle connections, wait time, timeout errors
- **N+1 Query Detection**: Parse P6Spy logs to identify N+1 query patterns
  - Pattern matching: same SQL template executed >10 times within <100ms

  - JSON format parsing for structured analysis
  - Buffer usage, execution time, and query plan visualization
- **Index Recommendations**: Analyze `pg_stat_user_tables` to suggest missing indexes

- Commands: `/postgres-analyze`, `/db-performance`

**Output**: Comprehensive performance report (`docs/performance/performance-report.md`)

**Real-world Impact**:

- **Time Saving**: Automated analysis replaces 2-3 hours of manual PostgreSQL profiling

### 2. smartadmin-manager-extractor (P2 - Refactoring)

**Location**: `productivity/refactoring/smartadmin-manager-extractor/`

**Purpose**: Auto-extract `@Transactional` methods from Service to Manager layer

**Problem Statement**:
- ArchUnit test `transactionalMustUseRollbackForThrowable` frequently fails
- Manual refactoring takes 20-30 minutes per violation
- Human error risk: forgetting constructor injection, incorrect method signatures

**Solution**:
- **JavaParser AST Manipulation**: Parse Service classes and extract methods to Manager layer
- **Template-based Generation**: Generate Manager classes from predefined templates
- **Triple Validation**: Compile + ArchUnit + Tests (auto-rollback on failure)
- **Git Safety**: Creates stash before execution, preserves refactoring history

**Execution Flow**:
1. Parse Service class structure
2. Identify `@Transactional` methods (ArchUnit violations)
3. Generate Manager class (if not exists)
4. Extract methods to Manager with proper dependencies
5. Update Service to call Manager methods
6. Validate: compilation → ArchUnit tests → unit tests
7. Rollback if any validation fails

**Triggers**:
- Keywords: "extract to Manager", "transactionalMustUseRollbackForThrowable fails", "refactor transaction"
- Commands: `/manager-extract <ServiceClass>`

**Time Saving**: 83% reduction (30 minutes → 5 minutes)

**Example**:
```bash
# Before: ArchUnit test fails
./gradlew :sa-admin:test --tests ArchitectureTest
# ❌ EmployeeService.saveEmployee() violates rule:
#    @Transactional must be in Manager layer

# Auto-fix with skill
/manager-extract EmployeeService
# ✅ Created EmployeeManager.saveEmployeeTransaction()
# ✅ Updated EmployeeService to call Manager
# ✅ ArchUnit PASSED
# ✅ All tests PASSED

# Generated code:
@Service
@RequiredArgsConstructor
public class EmployeeManager {
    private final EmployeeDao employeeDao;

    @Transactional(rollbackFor = Throwable.class)
    public void saveEmployeeTransaction(EmployeeEntity employee) {
        employeeDao.insert(employee);
    }
}
```

**Safety Features**:
- Git stash created before execution
- Automatic rollback on compilation errors
- Automatic rollback on ArchUnit failures
- Automatic rollback on test failures
- Preserves complete refactoring history in Git log

### 3. concurrency-safety-auditor (P1 - Quality)

**Location**: `extended/quality/concurrency-safety-auditor/`

**Purpose**: Concurrency safety audit with ⭐⭐⭐⭐⭐ risk rating system

**Capabilities**:
- **SpotBugs Custom Detectors**: Detect 8 concurrency anti-patterns
  - Check-then-act (non-atomic operations)
  - Double-checked locking
  - Unsafe collection operations
  - Race conditions in shared state
  - Deadlock potential
  - Thread-unsafe singletons
  - Improper synchronization
  - ConcurrentModificationException risks
- **Risk Rating System**: Quantitative assessment based on three factors
  - Formula: `Risk Score = (Probability × 0.4) + (Impact × 0.35) + (Actual Harm × 0.25)`
  - Output: ⭐ (negligible) to ⭐⭐⭐⭐⭐ (critical) rating
- **Fix Recommendations**: Generates corrected code snippets for each violation
- **Production-Ready Patterns**: Validates against SmartAdmin's existing concurrent implementations

**Triggers**:
- Keywords: "concurrency", "thread safety", "race condition", "deadlock detection"
- Commands: `/concurrency-audit`, `/thread-safety-check`

**Risk Assessment Model**:

| Rating | Probability | Impact | Actual Harm | Action |
|--------|-------------|--------|-------------|--------|
| ⭐⭐⭐⭐⭐ | >50% | Critical | Data corruption | Fix immediately |
| ⭐⭐⭐⭐ | 10-50% | High | Inconsistent state | Fix soon |
| ⭐⭐⭐ | 1-10% | Medium | Performance degradation | Schedule fix |
| ⭐⭐ | <1% | Low | Acceptable risk | Monitor |
| ⭐ | <0.1% | Negligible | No action needed | Document |

**Example Audit Report**:
```bash
./gradlew runConcurrencyAudit

# Output: docs/quality/concurrency-audit-report.md

## Summary
✅ 5 patterns rated ⭐⭐⭐⭐⭐ (Production-grade implementations)
✅ 3 patterns rated ⭐⭐⭐⭐ (Good, minor improvements possible)
⚠️  2 patterns rated ⭐⭐ (Low risk, fix recommended)

## Detailed Findings

### 1. SmartReloadManager.register() - Check-then-act non-atomic
- Risk: ⭐⭐ (Low)
- Probability: <0.01% (only during startup, single-threaded Spring Bean initialization)
- Impact: Single reload tag could be overwritten
- Actual Harm: Low (no production incidents observed)

**Current Code**:
```java
private void register(String tag, SmartReloadObject obj) {
    if (reloadObjectMap.containsKey(tag)) {  // Check
        log.error("Duplicate tag: " + tag);
    }
    reloadObjectMap.put(tag, obj);  // Act (non-atomic)
}
```

**Recommended Fix**:
```java
private void register(String tag, SmartReloadObject obj) {
    SmartReloadObject existing = reloadObjectMap.putIfAbsent(tag, obj);
    if (existing != null) {
        log.error("Duplicate tag: " + tag);
    }
}
```

### 2. SmartJobScheduler.addJob() - Race condition
- Risk: ⭐ (Negligible)
- Probability: <0.001%
- Impact: Job might be scheduled twice (ConcurrentHashMap handles this safely)
- Actual Harm: Negligible (idempotent job execution)
- Recommendation: No fix required, document the behavior
```

**SmartAdmin Implementations Validated**:
- `RepeatSubmitMemoryTicket`: ⭐⭐⭐⭐⭐ (Interner + synchronized, production-grade)
- `SerialNumberInternService`: ⭐⭐⭐⭐⭐ (Interner + synchronized, production-grade)
- `SmartReloadManager`: ⭐⭐⭐⭐ (ConcurrentHashMap, check-then-act non-atomic but low risk)
- `SmartJobScheduler`: ⭐⭐⭐⭐ (ConcurrentHashMap + ThreadPool, race condition negligible)

   - Checkstyle: Code style validation
   - PMD: Priority 1-3 violations detection

   - Run JaCoCo test coverage

   - Generate coverage reports (HTML + XML)
