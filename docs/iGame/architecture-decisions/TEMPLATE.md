## 使用說明

**如何使用此模板**:

1. **複製此文件**: 將 `TEMPLATE.md` 複製為新文件名（如 `013-new-decision.md`）
2. **更新 ADR 編號**: 將 `XXX` 替換為下一個可用編號（當前: 013）
3. **填寫所有章節**: 確保每個章節都有實質內容（不要留空）
4. **刪除範例與說明**: 移除所有範例文字和本使用說明
5. **提交審查**: 創建 Pull Request 並標記架構團隊審查
6. **更新索引**: 批准後更新 [README.md](./README.md) 索引

**質量檢查清單**:
- [ ] ADR 標題清晰描述決策內容
- [ ] 情境章節解釋了「為什麼」需要此決策
- [ ] 決策章節清晰陳述「做什麼」
- [ ] 至少列出 3 個正面影響和 2 個負面影響
- [ ] 評估了至少 2 個替代方案（包含「不採取行動」）
- [ ] 每個替代方案都有明確的拒絕理由
- [ ] 所有鏈接有效（相關文檔、ADR 交叉引用）
- [ ] 審查歷史記錄所有審查者的反饋

**撰寫提示**:
- **簡潔為上**: 目標是 200-400 行（含程式碼範例）
- **數據驅動**: 用具體數字（延遲、TPS、成本）而非模糊描述
- **讀者導向**: 假設讀者是 6 個月後的自己，需要理解當時的決策理由
- **誠實**: 承認負面影響和風險，不要只寫好處
