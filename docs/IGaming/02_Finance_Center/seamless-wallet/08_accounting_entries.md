# 未結算注單會計分錄修正

## 問題來源
文檔第 5.1 節第 302-306 行的會計分錄存在科目錯誤和結構問題。

**錯誤分錄** (原文):
> 分錄示例（結算贏）： 借：未結算注單負債 / 貸：玩家現金帳戶（本金）；借：收入抵減（GGR）/ 貸：玩家現金帳戶（贏金）。

## 核心問題

### 錯誤 1: 科目名稱錯誤
- ❌ 「收入抵減（GGR）」→ GGR 是**計算結果**，不是會計科目
- ✅ 應該使用「博彩成本」科目

### 錯誤 2: 分錄過於複雜
- 不需要分成兩筆（本金 + 贏金）
- 應該合併為一筆或明確標註步驟

## 正確的會計分錄

### 場景: 玩家投注 100 元，贏了 50 元

**階段 1: 下注**
```yaml
借: 玩家現金負債    100
貸: 未結算注單負債  100

含義: 100 元從「可用餘額」轉入「鎖定餘額」
```

**階段 2: 結算贏（本金 100 + 贏金 50 = 150）**
```yaml
借: 未結算注單負債  100
借: 博彩成本         50
貸: 玩家現金負債    150

含義: 返還本金 100 + 支付贏金 50
GGR = -50（成本）
```

**階段 3: 結算輸（本金不返還）**
```yaml
借: 未結算注單負債  100
貸: 博彩收入        100

含義: 玩家輸掉 100 元
GGR = +100（收入）
```

## 正確的科目設計


## GGR 計算

```
GGR 不是科目，是計算結果:

GGR = 博彩收入 - 博彩成本
    = (玩家輸的錢) - (玩家贏的錢)
```

## 決策總結

✅ **正確做法**:
- 使用「博彩收入」和「博彩成本」科目
- GGR 作為計算結果，不作為科目

❌ **錯誤做法**:
- 使用「收入抵減（GGR）」作為科目名稱
- 分錄結構過於複雜
