線上博彩(iGaming)產業在2025年全球市場規模已突破**$660億美元 GGR**,從平台技術到支付處理、合規監管到數據分析,形成了一套獨特且複雜的專業術語體系。本指南涵蓋8大核心領域的專業術語,為從業者提供完整的行業知識框架。

## 遊戲類型術語:博彩產品的核心分類

### 體育博彩核心概念

**Asian Handicap / 亞洲讓球盤** 亞洲讓球盤是一種通過半球(0.25, 0.5, 0.75)讓分消除平局結果的投注系統。此術語源自1998年記者 Joe Saumarez Smith 對印尼「hang cheng」投注的英文命名。在實際應用中,亞盤主導亞太市場的足球投注,僅提供兩種結果(勝/負),深受專業玩家青睞。**行業標準**要求提供分注功能,例如-0.25盤位時,投注額自動分配到0盤和-0.5盤。

**In-Play Betting / 滾球投注 (Gǔn Qiú Tóu Zhù)** 滾球投注允許玩家在賽事進行中即時下注,賠率根據場上情況實時更新。此類投注在某些市場佔據總投注額的**70%以上**,需要精密的風險管理系統支撐即時賠率調整。主要挑戰在於延遲控制、串謀偵測及快速結算。

**Parlay / Accumulator / 過關投注** 將多個獨立選項組合成單一投注,所有選項必須全部命中才能獲利。這種投注方式提供更高的潛在回報但風險也相應增加。行業標準通常將過關數量上限設定為**10-15個選項**。

**Bookmaker Margin (Vigorish) / 莊家水位** 莊家內建於賠率中的佣金,確保無論結果如何都能獲利。行業水平通常為**2-10%**,競爭激烈的市場水位更低,代表對玩家更有利的賠率。

### 撲克關鍵術語

**Rake / 抽水 (Chōu Shuǐ)** 撲克室從每局彩池或錦標賽報名費中收取的佣金。現金桌通常收取彩池的**2.5-10%**(設有上限);錦標賽採用固定費用模式(如$10+$1表示$1為抽水)。行業遵循「No flop, no drop」規則——若牌局在翻牌前結束則不收抽水。

**Rakeback / 返水** 將玩家支付的部分抽水以現金或紅利形式返還。返水比例從新玩家的**5%**到頂級VIP的**45%**不等,是吸引高頻玩家的重要激勵機制。

### 老虎機專業概念

**Volatility / 波動性** 描述遊戲風險和獎金分佈特性。**低波動性**遊戲提供頻繁的小額獎金(中獎頻率20-30%);**高波動性**遊戲中獎較少但單次獎金更大(中獎頻率10-15%),需要更多資金支撐。選擇適合個人風險偏好的波動性是玩家策略的重要組成。

**Progressive Jackpot / 累積獎金** 每次投注的一部分進入獎池,直到某位玩家贏得大獎。多家賭場可連結同一獎池,獎金可達數百萬美元。此類遊戲通常具有較低的基礎RTP,因部分回報轉移至大獎池。

**Megaways™ / 萬種賠付方式** Big Time Gaming 授權的動態捲軸系統,每次旋轉的支付線數量可變,最高可達**117,649種**賠付方式。採用連消機制,獲勝符號消除後新符號落下。

### 真人娛樂場術語

**Live Dealer / 真人荷官** 由真人荷官透過高清視頻即時串流操作的遊戲。Evolution Gaming 是市場領導者,運營多機位攝影棚提供24/7服務。支援「One Wallet」和「Fund Transfer」兩種整合方式。

**Baccarat Squeeze / 百家樂揭牌** 傳統的緩慢揭牌儀式,荷官逐漸翻開牌角製造懸念。Evolution Gaming 的揭牌版本使用**15+台高清攝影機**;Control Squeeze 功能允許玩家虛擬自行揭牌。此儀式在澳門VIP廳有深厚文化根基。

**Roads / 路單 (Lù Dān)** 顯示百家樂歷史結果的圖表系統,包括大路、大眼仔、小路、蟑螂路、珠盤路等。玩家用於識別模式並指導投注決策。

## 技術架構術語:平台建設的技術基礎

### 平台類型定義

**White-Label Platform / 白牌平台(包網)** 由第三方供應商提供的預建完整博彩平台,運營商以自有品牌上線運營。供應商提供基礎設施、遊戲、牌照、支付系統甚至客服,運營商專注於品牌推廣和玩家獲取。典型供應商包括 SOFTSWISS、GR8 Tech、Gamingtec。

**實際應用場景**:新進市場者可在**4-6週**內快速上線。供應商持有主牌照,運營商通過子牌照協議運營。營收分成通常為GGR的**20-50%**,設置費用$15,000-$50,000。

**Turnkey Solution / 交鑰匙解決方案** 完整預建但需運營商自行取得牌照的平台解決方案。相比白牌,運營商擁有更大的客製化彈性和「產品主權」。適合有經驗、計劃進入受監管市場的運營商。建置時間約**2-3個月**,包含可配置的PAM、CRM、支付閘道等模組化組件。

**Multi-Tenant Architecture / 多租戶架構** 單一軟體實例同時服務多個運營品牌(「租戶」)的架構設計。每個租戶可擁有獨立品牌、配置和用戶體驗,同時共享底層基礎設施。EveryMatrix 的 GamMatrix 即採用此架構,可從單一後台管理多個賭場品牌。

### 錢包整合方式

**Seamless Wallet / 無縫錢包** 玩家維持單一統一帳戶餘額,可即時跨所有遊戲和垂直產品(娛樂城、體育、撲克)使用。iGaming API 供應商與運營商的中央錢包系統即時通訊,處理每筆投注、獲勝和損失。此為現代運營商首選架構,提供**最佳玩家體驗**。

**Transfer Wallet / 轉帳錢包** 玩家需手動或程式化將資金從主錢包轉入各遊戲供應商的專用錢包才能遊戲。採用「轉入/轉出」模式,實施較無縫錢包簡單。部分供應商提供「自動轉帳錢包」改善用戶體驗。

### 遊戲聚合概念

**Game Aggregator / 遊戲聚合平台** 將數千款來自多個工作室的遊戲整合為單一API接入點的平台。Hub88、SOFTSWISS、Groove 等聚合商可透過**單一API**提供15,000+款遊戲,涵蓋100+供應商。整合通常在**3-7天**內完成。

**Unified API / 統一API** 標準化的應用程式介面,將多個遊戲供應商整合為單一接入點。Zenith 的 OneAPI 提供150+供應商的10,000+款遊戲存取,iGaming Deck 達到**13.8毫秒**的交付速度。採用RESTful架構、JSON格式回應、webhook即時事件支援。

### 後端系統組件

**PAM (Player Account Management) / 玩家帳戶管理系統** 管理用戶帳戶、錢包、支付流程、註冊、會話管理、KYC/AML控制的後端核心系統。EveryMatrix 的 GamMatrix PAM 運行時間達**99%以上**,支援詐欺偵測、負責任博彩功能和深度報表。Bragg Gaming 的 PAM 提供AI驅動的負責任博彩偵測。

**Back Office / 後台管理系統** 提供財務管理、行銷運營、客戶支援、商業智慧、玩家管理和合規報告工具的管理介面。包含深度交易檢視、自訂報表建構、統一存取控制等功能。

### 效能指標術語

**Latency / 延遲** 數據封包從用戶設備到服務器再返回所需時間(毫秒)。真人娛樂場需要**低於50毫秒**的延遲以確保流暢互動。Google研究顯示載入時間從1秒增至3秒,跳出率增加**32%**。

**Uptime SLA / 運行時間服務等級協議** 服務可用性的合約保證。領先iGaming平台保證**99.95-99.99%運行時間。99.99%(四個9)意味著每年停機時間僅**52.56分鐘。大型企業每小時停機損失可達$300,000-$100萬。

## 支付相關術語:資金流轉的關鍵環節

### 支付基礎設施

**PSP (Payment Service Provider) / 支付服務提供商** 第三方金融機構,使商家能接受信用卡/借記卡、銀行轉帳、電子錢包和替代支付方式。專精iGaming的PSP(如Paysafe、Nuvei、Corefy)了解高風險商戶要求,支援多幣種並提供專為博彩交易設計的反詐欺工具。**必須維持PCI DSS合規**,實施AML/KYC協議。

**Payment Gateway / 支付閘道** 安全傳輸商戶網站與收單銀行間交易數據的技術解決方案。加密敏感持卡人數據、驗證交易並即時回傳授權結果。博彩支付閘道需處理大量微交易、支援3D Secure驗證。

**Payment Orchestration / 支付編排** 透過單一API整合多個PSP、收單行和支付方式的技術層。Praxis Tech、Corefy等平台可連接**200+支付供應商**,實現智能路由和自動故障轉移,達成**85%以上**的受理率。

**Smart Routing / 智能路由** 根據預定規則和即時數據分析,自動將每筆交易導向最優處理器。考慮因素包括批准率、處理成本、地理位置、幣種和供應商運行狀態。現代路由引擎使用AI/ML演算法,每筆交易分析**100+數據點**。

### 支付方式詳解

**3D Secure (3DS) / 3D安全驗證** 為無卡交易增加額外驗證層的認證協議。「3D」指三個域:收單、發卡和互通域(卡組織)。對博彩運營商至關重要,因為它提供**責任轉移**(詐欺退款成為發卡行責任),可減少詐欺相關退款**70%以上**。品牌名稱:Visa Secure、Mastercard Identity Check。

**Chargeback / 退款(拒付)** 持卡人向發卡行爭議交易,導致款項撤銷並從商戶扣除。每次退款產生**$15-$70+**費用。博彩行業退款風險高,原因包括「友善詐欺」(玩家爭議合法損失)、家人爭議未授權博彩等。卡組織監控閾值通常為**0.9-1%**,超標將面臨罰款甚至終止服務。

**A2A Payments / 帳戶對帳戶支付** 無需信用卡網絡等中介,直接在銀行帳戶間轉移資金。包括手動銀行轉帳、直接扣款和開放銀行發起的支付。優勢包括更低處理成本(無交換費)、降低退款風險(交易不可撤銷)、透過銀行帳戶驗證內建KYC。A2A處理歐洲電商支付的**17%**。

**Open Banking / 開放銀行** 允許銀行與授權第三方在客戶同意下通過API安全共享金融數據的監管框架。在iGaming中實現即時銀行存款(Pay by Bank)、即時帳戶驗證進行KYC、負責任博彩的可負擔性檢查。主要供應商:TrueLayer、Yaspa、Trustly。

### 加密貨幣支付

**Stablecoin Payments / 穩定幣支付** 使用與法幣(通常為美元)掛鈎的加密貨幣進行支付,消除價格波動。USDT(Tether)和USDC(Circle)最為常見。優勢包括消除運營商和玩家的波動風險、即時結算等值法幣價值、可預測的營收流。領先運營商**60%以上**的加密交易量通過穩定幣處理。

**Crypto Payment Processors / 加密貨幣支付處理器** 專業供應商使商家能接受加密支付,通常支援自動轉換為法幣。主要供應商包括:NOWPayments(350+幣種、0.5%費用)、B2BINPAY(80+幣種、EU監管)、CryptoProcessing/CoinsPaid(iGaming專家、自動轉EUR)。

### 支付運營概念

**Rolling Reserve / 滾動儲備金** 支付處理器保留一定比例的交易收入(通常**5-15%)於儲備帳戶中**90-180天,以應對潛在退款、退費或商戶違約。這是高風險博彩商戶的標準要求,對運營商現金流有顯著影響。建立良好處理記錄後可降低比例。

**Payment Success Rate / 支付成功率** 成功授權並完成的交易百分比。行業基準:優化設置應達**85%以上**。影響因素包括3DS實施、本地收單、智能路由。每提升1%直接影響營收。優化策略:多PSP、本地收單、智能路由、重試邏輯。

## 風控與合規術語:監管要求的核心框架

### 玩家驗證流程

**KYC (Know Your Customer) / 認識你的客戶** 在建立業務關係或允許真錢遊戲前,驗證客戶身份的綜合流程。包括身份驗證(確認玩家身份)、文件驗證(驗證護照、駕照、身份證真實性)、年齡驗證(確保符合法定年齡18+或21+)、地址驗證(通過水電單或銀行對帳單確認)。

**實際應用**:註冊時玩家提交個人資料和證件照片。運營商使用自動驗證系統(如iDenfy、Sumsub、Persona)即時驗證文件。大額提款等高風險活動觸發額外驗證步驟。**UKGC要求在UK市場存款前完成驗證**。

**EDD (Enhanced Due Diligence) / 加強盡職調查** 對高風險客戶(包括政治公眾人物PEP、高淨值人士或異常交易模式者)實施的額外驗證程序。包括資金來源驗證、財富來源文件、加強交易監控、高管批准帳戶延續、更頻繁的帳戶審查。英國某運營商因允許已知住在社會住宅的客戶存入£186,000而未進行適當EDD被處罰。

### 反洗錢體系

**AML (Anti-Money Laundering) / 反洗錢** 旨在防止犯罪分子通過博彩平台將非法所得偽裝為合法收入的法規框架和程序。包括客戶盡職調查(CDD)、加強盡職調查(EDD)、交易監控、可疑活動報告、員工培訓、記錄保存(通常**5年以上**)。2023年博彩行業AML罰款超過**$4.75億**。

**SOF (Source of Funds) / 資金來源** 驗證客戶用於博彩交易的資金來源於合法合規途徑。觸發時機通常為存款超過門檻或針對高風險客戶。所需文件包括銀行對帳單、薪資單、稅務申報、投資記錄、房產出售文件等。

**SAR (Suspicious Activity Report) / 可疑活動報告** 當交易看起來異常或與客戶正常博彩行為不一致時,向金融情報單位(FIU)提交的正式報告。需報告情況包括:與玩家檔案不符的大額現金存款、異常投注模式(存款、極少遊戲後提款)、多帳戶顯示協調活動、帳戶間快速資金轉移。

### 負責任博彩工具

**Self-Exclusion / 自我排除** 允許個人在指定期間(通常6個月至終身)禁止自己使用博彩平台的自願計劃。**GamStop**(英國)自2020年3月起為強制性多運營商計劃,**83%用戶報告減少或停止博彩**。排除期間獲得的獎金可能被取消。

**Cooling-Off Period / 冷靜期** 較短的、通常可撤銷的博彩暫停,有別於正式的自我排除。通常範圍從24小時到數週,防止玩家衝動決定立即恢復博彩。

**Deposit/Loss/Session Limits / 存款/損失/時間限額** 玩家自設的投注控制工具。存款限額設定日/週/月最大存款金額;損失限額設定時間段內最大損失;時間限額限制單次會話或總遊戲時長。**提高限額通常需要24-72小時延遲生效**,降低則立即生效。提供可自訂上限的運營商,支出投訴減少**31%**。

**Reality Checks / 現實提醒** 定期彈出通知,提醒玩家已過時間、花費金額和當前會話狀態。通常設定間隔(15、30、60分鐘),顯示遊戲時長和投注金額。幫助玩家保持對活動水平的意識。

### 遊戲公平性概念

**RTP (Return to Player) / 玩家回報率** 遊戲長期理論上返還給玩家的總投注金額百分比。例如96% RTP意味著每投注€100理論返還€96。基於數百萬次遊戲計算,非單次會話結果。遊戲開發時設定,發布後不可更改。

**監管要求**:Malta MGA最低**85%** RTP;UK UKGC自2023年6月起老虎機要求最低**99.9%**(從標準95%提高)。線上娛樂城通常範圍**95-98%**。

**RNG (Random Number Generator) / 隨機數字生成器** 確保每次遊戲結果完全隨機和不可預測的軟體算法。分為真隨機數生成器(TRNG,使用物理事件,iGaming中因成本較少使用)和偽隨機數生成器(PRNG,產生統計上無法區分的隨機性)。必須經認可測試實驗室認證,定期審計確保持續合規。

**House Edge / 莊家優勢** 賭場對玩家的數學優勢,以每次投注預期保留的百分比表示。計算:莊家優勢 = 100% - RTP。各遊戲類型:21點約0.5-2%(最優策略)、百家樂莊家約1.06%、歐式輪盤約2.7%、老虎機2-15%。

### 遊戲測試認證機構

**eCOGRA**是2003年成立於英國的電子商務線上博彩監管與保證機構,獲ISO/IEC 17025:2017認證,在**25+司法管轄區**獲認可,提供RNG測試、RTP驗證、爭議解決服務。**GLI**(國際博彩實驗室)擁有30+年經驗,服務覆蓋全球**480個司法管轄區**。**BMM Testlabs**成立於1981年,是業內最古老的測試機構。

## 監管機構術語:全球牌照體系解析

### 頂級監管機構

**UKGC (UK Gambling Commission) / 英國博彩委員會** 2007年依據《2005年博彩法》成立,被視為全球「黃金標準」。管轄英格蘭、威爾士、蘇格蘭的所有線上和實體博彩。牌照類型包括營運牌照、個人管理牌照(關鍵人員必備)和場所牌照。申請處理約**16週**,申請費£370,年費基於毛博彩收益(GGY)。遠程博彩稅為毛利潤的**21%。自2020年3月起強制參加GamStop,2020年4月起禁止信用卡存款。自2020年以來罰款總額超過**£1億。

**MGA (Malta Gaming Authority) / 馬耳他博彩管理局** 2001年成立,歐盟首個監管線上博彩的成員國。控制全球約**10%虛擬賭場**,305+活躍持牌者,貢獻馬耳他GDP的**12%以上**。牌照類型包括:Type 1(RNG遊戲)、Type 2(固定賠率投注)、Type 3(P2P遊戲)、Type 4(技巧遊戲)以及B2B關鍵遊戲供應牌照。必須為EU/EEA公司,服務器須位於馬耳他。處理時間**3-6個月**,初始費用€25,000+。

**Curaçao Gaming Authority / 庫拉索博彩管理局** 自1996年運營,是最古老的iGaming司法管轄區之一。2024年實施新監管框架LOK(國家博彩法),取消子牌照系統。年費ANG 120,000,稅率為淨利潤的**2%**(至2026年),無VAT。受限市場:美國、澳洲、荷蘭、法國、庫拉索。新LOK框架旨在提升至MGA/UKGC標準。

## 商業模式術語:行業運營的架構設計

### 基礎商業模式

**B2B (Business-to-Business) / 企業對企業** 公司向其他企業而非終端消費者提供產品、服務或技術。在iGaming中,B2B供應商向直接服務玩家的運營商授權技術、遊戲或服務。Evolution Gaming是領先的B2B真人娛樂場供應商。營收來自授權費、設置費和營收分成(GGR百分比)。

**B2C (Business-to-Consumer) / 企業對消費者** 公司直接向個人玩家提供博彩服務。B2C運營商經營線上娛樂城、體育投注和撲克室,通過玩家存款、莊家優勢和博彩活動產生營收。需要在每個接受玩家的司法管轄區持有博彩牌照。

### 解決方案與合作模式

**White-Label (包網) / 白牌方案** 可即用的iGaming平台,運營商以自有品牌使用供應商的基礎設施、牌照、遊戲和支付系統。「包網」一詞在亞洲市場常用。**1-2個月**內可上線,投資最小。供應商持主牌照,營收分成GGR的20-50%。

**Revenue Sharing Models / 營收分成模式** B2B供應商按運營商GGR百分比收費而非固定授權費的付款安排。使供應商和運營商利益一致。白牌供應商通常收取**20-50%** GGR分成,遊戲供應商可能收取遊戲特定GGR的10-15%。階梯結構可隨交易量增加降低百分比。

**Aggregation Platforms / 聚合平台** 通過單一整合提供多個遊戲供應商、支付處理器或服務統一存取的B2B平台。Hub88、SOFTSWISS Game Aggregator聚合100+工作室的15,000+款遊戲。運營商一次整合即可避免管理數十個獨立合約和API。

### 牌照結構

**Master License / 主牌照** 司法管轄區監管機構核發的主要博彩牌照,授予進行博彩活動的權利並可向其他運營商發放子牌照。持有者對子牌照持有者充當微型監管者。在庫拉索,僅**4家公司**持有主牌照。2025年庫拉索改革取消了子牌照系統。

**Sublicensing / 子牌照** 由主牌照持有者向第三方運營商發放的博彩許可,授予相同營運權但無法進一步發放子牌照。歷史上庫拉索子牌照成本約**$16,900**,處理時間6週。菲律賓PAGCOR也提供子牌照模式。

## 數據與分析術語:業績衡量的指標體系

### 核心營收指標

**GGR (Gross Gaming Revenue) / 毛博彩收入** 玩家總投注額減去支付給玩家的總獎金。代表運營商的「頂線」營收。 **公式**:GGR = 總投注額 - 總玩家獎金

GGR是大多數司法管轄區(馬耳他、英國、多數美國州)的主要稅基,用於衡量市場規模、比較運營商表現,常用於聯盟營收分成協議。2023年美國博彩行業GGR達**$666.5億**。

**NGR (Net Gaming Revenue) / 淨博彩收入** 從GGR扣除所有博彩相關成本後的實際獲利營收。 **公式**:NGR = GGR - 紅利 - 稅費 - 佣金 - 營運成本 - 費用

NGR反映真正的運營商盈利能力,為投資者首選的財務評估指標。促銷成本應保持在GGR的**20%以下**,強勢運營商的NGR利潤率維持在GGR的**50-70%**。

**Hold Percentage / 持有率** 賭場保留的總投注額百分比。 **公式**:持有率 = GGR / 總投注額 × 100%

行業基準:老虎機2.5-10%(因RTP而異)、桌遊15-25%、體育投注理論持有5-8%。

### 玩家價值指標

**LTV (Player Lifetime Value) / 玩家終身價值** 預期玩家在與平台的整個關係期間產生的總淨營收。 **公式**:LTV = ARPU × 平均玩家生命週期 - 獲取和留存成本

用於確定最大允許CAC、指導營銷預算分配、通知VIP計劃投資。LTV必須超過**3倍CAC**才能盈利。高價值玩家的LTV可達平均值的10-100倍。

**CAC (Customer Acquisition Cost) / 客戶獲取成本** 獲取一位新存款客戶的總成本,包括所有營銷、廣告、銷售及相關間接費用。 **公式**:CAC = 總銷售和營銷費用 / 新獲取客戶數

行業基準:美國/英國iGaming CPA每FTD **$200-500+**;亞太地區低至$0.93;低CAC($50-80)可能表示低質量「紅利獵人」流量。

**LTV:CAC Ratio / 終身價值與獲客成本比率** 比較客戶終身價值與獲取成本的比率。

- **1:1** = 每次獲取虧損(扣除其他成本前損益平衡)   
- **3:1** = 健康基準(行業標準)    
- **4:1+** = 優秀商業模式
- **5:1+** = 可能投資增長不足 
### 轉換與參與度指標

**Conversion Rate / 轉換率**

- 訪問到註冊轉換:基準**20-30%**為健康
- 註冊到FTD轉換:基準**12-18%**為典型,15-18%為強勁    

低訪問到註冊:落地頁/UX問題;低註冊到FTD:KYC摩擦、支付問題、紅利吸引力弱。

**FTD (First Time Depositor) / 首次存款者** 完成首次真錢存款的新註冊玩家。關鍵指標包括FTD數量、FTD率、每FTD成本(CPFTD)、首次存款時間(TTFD)。優質FTD應在**7天內**完成第二次存款。

**Retention Rate / 留存率** 在指定期間內持續活躍參與的玩家百分比。 **公式**:留存率 = (期末用戶 / 期初用戶) × 100%

30天留存達**70-80%**表示強勁成功;D1留存(移動端)25-30%;D30留存最低3-5%以覆蓋獲取成本;**5%留存提升可帶來25-95%利潤增長**。

**DAU/MAU Stickiness / 黏著度** **公式**:黏著度 = DAU / MAU × 100%

- 20% = 用戶每月參與約6天   
- 50% = 用戶隔天參與
- 70%+ = 極高黏著度(每日習慣)   

iGaming娛樂城典型值**15-25%**。

### 營銷分析指標

**CPA (Cost Per Acquisition) / 每次獲取成本** 為獲取一位符合特定標準(註冊、FTD等)的客戶支付的固定成本。聯盟支付的主要模式,預算規劃指標。

**ROAS (Return on Ad Spend) / 廣告投資回報率** 每花費一美元廣告產生的營收。 **公式**:ROAS = 廣告營收 / 廣告支出 × 100%

基準:200%(2:1)= 最低損益平衡目標;400-800%(4:1至8:1)= 良好表現;6-9個月內達到100% ROAS損益平衡是目標;超過12個月回本令人擔憂。

**Cohort Analysis / 世代分析** 按共同特徵(通常為獲取日期)對玩家分組,分析行為模式隨時間的變化。應用包括FTD月份世代的LTV分析、獲取渠道世代的質量比較、紅利類型世代的促銷效果評估。

### 風險與詐欺指標

**Chargeback Rate / 退款率** 被持卡人爭議並撤銷的交易百分比。卡組織閾值通常為**0.9-1.0%**,超標觸發處罰或終止帳戶。商戶退款爭議勝率僅**32%**。

**Bonus Abuse Detection / 紅利濫用偵測** 關鍵指標包括:多帳戶創建速度(同設備/IP快速創建)、設備/瀏覽器指紋匹配、促銷代碼兌換模式、存款到提款循環(紅利後快速提款)、低風險投注模式。偵測方法包括設備指紋、IP/地理位置追蹤、速度檢查、行為分析。

**Risk Scoring / 風險評分** 為交易、帳戶或玩家分配的數值評級,表示詐欺概率。組成部分:設備信任評分、行為異常評分、交易模式評分、身份驗證評分、歷史帳戶活動。分數通常為0-100或0-1000,設定自動批准、人工審核、自動拒絕的閾值。

## 營運與行銷術語:玩家經營的核心策略

### 紅利體系

**Welcome Bonus / 歡迎獎金** 新玩家註冊或首次存款時提供的促銷優惠。最常見為100%存款匹配,對玩家獲取至關重要。

**First Deposit Bonus (FDB) / 首存紅利** 專門針對玩家首次存款給予的獎金。通常為100-200%匹配,設有最高上限。

**No Deposit Bonus (NDB) / 免存款紅利** 無需存款即可獲得的獎金,允許無風險遊戲。通常金額較小($10-50)或免費旋轉,設有高額流水要求。

**Cashback / Rakeback / 返水** 返還玩家一定比例損失的機制。Cashback通常為淨損失的**5-15%**;Rakeback專指撲克抽水返還,根據VIP等級從5%到45%不等。

### 流水要求機制

**Wagering Requirements / 流水要求** 紅利金額在可提款前必須投注的倍數。 **計算**:紅利 × 倍數 = 需完成流水(如$100 × 30x = $3,000)

行業標準:**20-40倍**視為合理;50倍以上視為偏高。

**Game Weighting / 遊戲貢獻比例** 不同遊戲類型對流水要求的貢獻百分比。標準權重:老虎機100%、桌遊10-20%、真人娛樂場10-20%、視頻撲克0-10%。此設計防止玩家利用低莊家優勢遊戲套利。

**Bonus Abuse / 紅利濫用** 通過詐欺或非預期方式利用紅利條款。類型包括多帳戶(gnoming)、串謀投注、籌碼傾倒、套利。預防措施:KYC驗證、行為監控、嚴格條款、遊戲權重設定。

### VIP與忠誠計劃

**VIP Program / 貴賓計劃** 為最高價值玩家提供的專屬獎勵計劃。通常僅限邀請,提供個性化服務、更高限額、專屬活動。

**Loyalty Points / Comp Points / 忠誠積分** 通過投注活動賺取、可兌換獎勵的積分。標準比率:每投注$10-20獲1點;100點 = $1紅利。用於階梯系統(銅、銀、金、白金、鑽石)。

**High Roller / Whale / 豪賭客/鯨魚** High Roller指持續大額投注的玩家,通常存款$10,000+,單注$300-500+。Whale是極端高注額賭客,可能單次損失數十萬至數百萬,享受終極VIP待遇(私人飛機、豪華住宿)。此類玩家對賭場營收關鍵但代表高波動風險。

### 玩家獲取模式

**CPA vs Revenue Share vs Hybrid**

- **CPA(單次獲取成本)**:每合格玩家支付固定金額,通常要求FTD和最低投注
- **Revenue Share(收益分成)**:聯盟獲得推薦玩家淨博彩收入的百分比,娛樂城/撲克20-60%,體育投注15-40%
- **Hybrid(混合)**:結合前期CPA支付和持續收益分成(如$100 CPA + 20% RevShare)
    

### 玩家留存策略

**Churn Rate / 流失率** 在特定時間段內停止使用平台的玩家百分比。首年流失50-80%屬常見;月度活躍留存70%以上為強勁。5%流失降低可顯著提升LTV。

主要流失驅動因素:支付摩擦和慢速提款、糟糕的移動端UX(70-80%活動在移動端)、紅利疲勞/不清晰的流水要求、遊戲種類不足。

**Reactivation Campaigns / 喚醒活動** 針對非活躍/休眠玩家重新參與的營銷努力。細分:7-14天不活躍(溫)、30天(涼)、90+天(冷)。策略:個性化紅利、限時優惠、「我們想念你」訊息。成本低於新獲取。

## 結語:iGaming術語體系的實踐價值

本指南涵蓋的**8大類別、200+專業術語**構成了iGaming行業從平台建設、支付處理、合規監管到數據分析的完整知識框架。隨著行業持續演進——庫拉索2025年監管改革、AI驅動的個性化、區塊鏈整合——從業者需持續更新對這些核心概念的理解。

對於多商戶白標平台運營者,關鍵在於深度理解**PAM架構、無縫錢包整合、GGR/NGR計算邏輯和LTV:CAC優化**;對於支付處理專業人員,**智能路由、滾動儲備金、退款率控制和PCI DSS合規**是核心知識;而風控合規團隊則需精通**KYC分層驗證、EDD觸發條件、SAR提交流程和RNG認證標準**。

掌握這套術語體系,不僅是行業溝通的基礎,更是做出正確商業決策的前提。

### B.4 使用規範

#### 文檔撰寫規則

1. **標題/章節名**: 必須使用主術語
   ```markdown
   ✅ 正確：## 2.1 Withdrawal Approval Flow
   ❌ 錯誤：## 2.1 提款檢查流程
   ```

2. **首次出現**: 使用主術語 + 英文全稱
   ```markdown
   ✅ 正確：提款審核流程 (Withdrawal Approval) 包含三個階段...
   ❌ 錯誤：提款檢查流程包含三個階段...
   ```

3. **後續引用**: 可使用主術語或可接受變體
   ```markdown
   ✅ 正確：Withdrawal Approval 完成後...
   ✅ 可接受：Withdrawal Review 階段需要...（描述特定階段時）
   ❌ 錯誤：Withdrawal Check 完成後...
   ```

4. **代碼/API**: 必須使用主術語的駝峰式命名

#### 交叉引用規範

當在文檔中引用其他章節時，使用主術語確保一致性：

```markdown
✅ 正確：詳細邏輯參見 [05-01 §3.1 投注驗證 (Bet Validation)](../05_Risk_Management/05-01_Risk_Control_System.md#31-bet-validation)

❌ 錯誤：詳細邏輯參見 [05-01 §3.1 投注檢查](...)
```

#### 多語言文檔處理

| 語境 | 規則 | 示例 |
|------|------|------|
| **中文文檔** | 中文主術語 + 英文縮寫（首次） | 提款審核流程 (Withdrawal Approval) |
| **英文文檔** | 英文主術語 + 中文註釋（可選） | Withdrawal Approval (提款審核流程) |
| **代碼註釋** | 英文主術語 + 簡短說明 | `// Withdrawal Approval: validates and processes withdrawal requests` |
| **API 文檔** | 英文主術語（RESTful） | `POST /api/withdrawals/approval` |

#### 術語衝突解決

當不同模塊對同一概念使用不同術語時：

1. **識別衝突**: 通過 Grep 工具搜索變體術語
   ```bash
   grep -rn "Withdrawal Check\|Payout Approval" docs/IGaming/
   ```

2. **評估影響**: 確認需要更新的文件範圍

3. **統一替換**: 使用主術語替換所有變體
   ```bash
   # 示例：將 "Withdrawal Check" 替換為 "Withdrawal Approval"
   find docs/IGaming/ -type f -name "*.md" -exec sed -i 's/Withdrawal Check/Withdrawal Approval/g' {} +
   ```

4. **驗證一致性**: 重新搜索確認無遺漏
   ```bash
   grep -rn "Withdrawal Check" docs/IGaming/  # 應返回 0 結果
   ```
