# i18n Generator - Quick Reference

**Sprint:** 3 (Weeks 9-11) | **Priority:** P1 - Roadmap #1 | **Status:** 🚧 Skeleton

## One-Line Summary
Generate complete i18n infrastructure (backend MessageSource + frontend Vue I18n) for global deployment.

## When to Use
- Multi-language support needed
- Global deployment
- Locale-specific formatting
- RTL layout support
- Translation management

## What It Generates
✅ Backend MessageSource config
✅ Frontend Vue I18n setup
✅ Locale formatting (dates, numbers, currency)
✅ RTL layout support
✅ Translation key extraction
✅ Missing translation detection
✅ Backend ↔ Frontend sync
✅ Translation workflow

## Quick Example
```
User: "Add i18n to UserModule for Chinese, English, Japanese, Arabic"
→ Generates complete i18n support in one command
```

## Success Metric
**Deploy in 5+ languages with one command**

## Integration
- Works with: `smartadmin-crud-generator`, `smartadmin-vue-crud`
- Uses: Spring MessageSource, Vue I18n
- Compatible: All SmartAdmin modules
