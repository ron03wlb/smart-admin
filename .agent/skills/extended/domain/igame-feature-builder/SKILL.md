# iGame Feature Builder

Implement iGaming domain features including VIP system, Wallet API, Bonus engine, and Risk control.

## When to Use

- Building VIP tier system
- Implementing wallet API
- Creating bonus engine
- Risk control integration

## Features

1. **VIP System**: Tier management, benefits, upgrade rules
2. **Wallet API**: Balance, transactions, multi-currency
3. **Bonus Engine**: Welcome bonus, reload, cashback
4. **Risk Control**: Limits, alerts, manual review
