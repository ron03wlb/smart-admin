# iGame PM Analyst - Quick Reference

## 分析流程

1. **需求澄清** → 確認業務目標
2. **JTBD 分析** → 理解用戶任務
3. **功能規劃** → 定義範圍
4. **風險評估** → 識別風險
5. **PRD 輸出** → 結構化文檔

## PRD 模板結構

```markdown
# [功能名稱] PRD

## 1. 概述
- 背景
- 目標
- 範圍

## 2. 用戶故事
- 作為 [角色]，我想要 [功能]，以便 [價值]

## 3. 功能需求
### 3.1 [功能模塊 1]
- 用例描述
- 流程圖
- 驗收標準

## 4. 非功能需求
- 性能
- 安全
- 合規

## 5. 風險評估
| 風險 | 影響 | 機率 | 緩解措施 |

## 6. 里程碑
```
