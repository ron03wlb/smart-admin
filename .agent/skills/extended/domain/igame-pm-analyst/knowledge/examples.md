# iGame PM Analyst - Examples

## 範例: VIP 系統 PRD

```markdown
# VIP 會員系統 PRD

## 1. 概述

### 背景
目前平台缺乏會員等級系統，用戶忠誠度較低，需建立 VIP 機制提升留存。

### 目標
- 提升 DAU 15%
- 提升用戶 LTV 20%
- 降低 Churn Rate 10%

### 範圍
- VIP 等級定義 (Bronze → Diamond)
- 升降級規則
- 等級權益
- 積分系統

## 2. 用戶故事

**US001**: 作為玩家，我想要查看我的 VIP 等級和進度，以便了解我的會員狀態。

**US002**: 作為 VIP 玩家，我想要獲得專屬獎金加成，以便獲得更好的遊戲回報。

## 3. 功能需求

### 3.1 等級定義

| 等級 | 積分門檻 | 獎金加成 | 專屬權益 |
|------|----------|----------|----------|
| Bronze | 0 | 1.0x | - |
| Silver | 1,000 | 1.2x | 專屬客服 |
| Gold | 5,000 | 1.5x | 優先提款 |
| Platinum | 20,000 | 2.0x | VIP 活動 |
| Diamond | 100,000 | 3.0x | 專屬經理 |

## 4. 風險評估

| 風險 | 影響 | 機率 | 緩解措施 |
|------|------|------|----------|
| 獎金成本超支 | 高 | 中 | 設定月度上限 |
| 等級通膨 | 中 | 低 | 定期調整門檻 |
```
