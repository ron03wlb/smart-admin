# Fraud Detection Pattern Generator

Generate fraud detection and risk control systems for iGaming platforms including multi-account detection, bonus abuse prevention, and KYC/AML automation.

## When to Use

- Implementing risk control systems
- Multi-account detection
- Bonus abuse prevention
- KYC/AML compliance

## Detection Patterns

1. **Multi-Account Detection**: Device fingerprint, IP analysis, behavior patterns
2. **Bonus Abuse**: Velocity checks, profit/loss ratios, coordinated betting
3. **Payment Fraud**: Chargeback patterns, velocity limits, amount thresholds
4. **Money Laundering**: Transaction patterns, structuring detection

## Workflow

1. Analyze risk requirements
2. Generate detection rules
3. Create alert triggers
4. Implement action handlers
5. Generate reports
